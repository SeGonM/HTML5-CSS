# Carpeta assest

Esta carpeta se creó para guardar las imágenes del proyecto.

Coloca aquí tus archivos de imagen (jpg, png, svg, ...) dentro de la carpeta `assest`.

Puedes subir imágenes desde la interfaz web de GitHub (Arrastrar y soltar) o usando git:

```bash
git add assest/tu-imagen.png
git commit -m "Añadir imagen: tu-imagen.png"
git push
```
