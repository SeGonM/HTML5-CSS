# 3.6. Composición y espaciado

Una interfaz se siente ordenada cuando el espacio, la alineación y las proporciones son consistentes. No se trata de añadir márgenes al azar: se trata de crear relaciones visuales que ayuden a entender qué elementos pertenecen juntos y qué contenido es más importante.

## Ritmo vertical

El ritmo vertical es la repetición coherente de espacios y alturas de línea. Una escala pequeña de espaciado ayuda a que títulos, párrafos, listas y secciones se sientan relacionados.

```css
:root {
  --space-1: 0.5rem;
  --space-2: 1rem;
  --space-3: 1.5rem;
  --space-4: 2.5rem;
}

.articulo h2 {
  margin-block: var(--space-4) var(--space-2);
}

.articulo p + p {
  margin-block-start: var(--space-2);
}
```

El ritmo no exige que todas las distancias sean iguales. Una separación pequeña puede agrupar una etiqueta con su título, mientras una mayor separación puede indicar el inicio de una sección nueva.

Para evitar márgenes enfrentados y colapso accidental, se puede usar `gap` en un contenedor flex o grid:

```css
.grupo-de-campos {
  display: grid;
  gap: 1rem;
}
```

## Proporción y alineación

La alineación crea relaciones claras entre los elementos. Un encabezado, un párrafo y una imagen pueden compartir un eje; una barra lateral puede tener un ancho estable mientras el contenido principal ocupa el espacio restante.

```css
.contenido {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(14rem, 20rem);
  gap: 2rem;
  align-items: start;
}
```

`minmax(0, 1fr)` permite que la columna principal se reduzca sin desbordar por contenido largo. Las proporciones deben adaptarse a la cantidad de contenido y al tamaño de pantalla; una composición rígida puede dejar de funcionar cuando cambian el texto o el viewport.

Las propiedades lógicas expresan el espaciado según el flujo de lectura:

```css
.tarjeta {
  padding-block: 1.5rem;
  padding-inline: 1rem;
  margin-block-end: 2rem;
}
```

Así, el mismo estilo funciona mejor en idiomas y modos de escritura distintos que si asumiera siempre las direcciones físicas arriba, derecha, abajo e izquierda.

## Espacio en blanco

El espacio en blanco es el área sin contenido que rodea o separa elementos. No es espacio desperdiciado: permite agrupar, separar, dar énfasis y hacer más fácil la lectura.

- Poco espacio entre elementos relacionados ayuda a percibirlos como un grupo.
- Más espacio entre grupos hace evidente el cambio de tema o sección.
- El espacio alrededor de texto mejora su legibilidad, siempre que la línea no sea demasiado ancha.
- Un espaciado consistente suele ser más importante que usar muchos valores diferentes.

No dependas de secuencias de espacios en el HTML para componer una página. Usa CSS para el espacio visual; reserva el contenido textual y su estructura para HTML.

## Alineación visual y óptica

Una alineación matemáticamente exacta no siempre se percibe como equilibrada. Por ejemplo, un icono puede necesitar una corrección óptica pequeña respecto al texto. Primero establece una alineación consistente con flex o grid y luego aplica ajustes mínimos cuando haya una razón visual clara.

```css
.boton {
  display: inline-flex;
  align-items: center;
  gap: 0.5em;
}
```

`align-items` alinea los hijos en el eje transversal del contenedor flex; `gap` mantiene una distancia explícita entre ellos, sin depender de márgenes individuales.

## Comprobar la composición

Revisa la página con contenido real y en distintos anchos:

1. Comprueba que títulos, texto y controles compartan alineaciones intencionales.
2. Observa si el espacio distingue grupos sin separar elementos relacionados.
3. Prueba cadenas largas, traducciones y texto ampliado.
4. Revisa los cambios de layout en pantallas estrechas.
5. Ajusta el ritmo con una escala pequeña en vez de acumular excepciones.

La composición debe apoyar la jerarquía y la lectura. Si una regla de espaciado oculta contenido o dificulta el uso, la prioridad es corregir la experiencia, no conservar la simetría visual.

## En resumen

- El ritmo vertical se construye con una escala coherente y jerarquías claras.
- `gap` funciona bien para separar los hijos de contenedores flex y grid.
- La alineación y las proporciones deben adaptarse al contenido y al espacio disponible.
- El espacio en blanco organiza la información y también es parte del diseño.
- Comprueba la composición en condiciones reales, no solo con el texto de ejemplo.
