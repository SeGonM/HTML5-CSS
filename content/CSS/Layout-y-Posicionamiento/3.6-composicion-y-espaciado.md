# 3.6. Composición y espaciado

Una interfaz se siente ordenada cuando el espacio, la alineación y las proporciones son consistentes. No se trata de añadir márgenes al azar: se trata de crear relaciones visuales que ayuden a entender qué elementos pertenecen juntos y qué contenido es más importante.

## Recordatorio: definir variables en `:root` antes de empezar

Antes de decidir cuánto espacio tendrá cada elemento, define una pequeña escala de valores reutilizables en `:root`. `:root` representa el elemento raíz del documento y permite declarar variables CSS disponibles para toda la página.

```css
:root {
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-3: 0.75rem;
  --space-4: 1rem;
  --space-5: 1.5rem;
  --space-6: 2rem;
  --space-7: 3rem;

  --content-max: 70ch;
  --radius-card: 0.5rem;
  --line-body: 1.6;
}
```

Una variable se define con dos guiones (`--nombre`) y se utiliza con `var()`:

```css
.articulo {
  max-inline-size: var(--content-max);
  margin-inline: auto;
  padding: var(--space-4);
  border-radius: var(--radius-card);
}

.articulo p {
  line-height: var(--line-body);
}
```

Esto tiene una razón práctica: si descubres que todo el sitio necesita un poco más de aire, cambias `--space-4` una vez en lugar de buscar decenas de valores distintos. Las variables no hacen que el diseño sea automáticamente bueno; ayudan a que las decisiones sean consistentes y fáciles de ajustar.

### Cómo elegir una variable

El nombre debe describir la función o la escala, no una apariencia accidental:

```css
/* Mejor: describe el papel del valor. */
:root {
  --space-section: 3rem;
  --space-card: 1.5rem;
}

/* Peor: describe un componente concreto. */
:root {
  --margin-left-card: 17px;
}
```

Puedes crear variables para espaciado, colores, tamaños máximos, radios y alturas de línea. Para medidas relacionadas con texto y espaciado, `rem` suele ser una base consistente; sus diferencias con `px`, `em` y `%` se explican en [2.4. Unidades CSS modernas](../Modelo-en-caja/2.4-unidades-css-modernas.md). `var()` y `calc()` permiten reutilizar y combinar estos valores, como se vio en [2.6. Funciones CSS](../Modelo-en-caja/2.6-funciones-css.md).

### Variables con valores alternativos

Si una variable no existe, `var()` puede recibir un valor de respaldo:

```css
.panel {
  padding: var(--space-panel, 1rem);
}
```

Aquí se usa `--space-panel` si está definida; si no, se usa `1rem`. Esto evita que una declaración quede inválida por una variable mal escrita.

### Un conjunto de tokens para una página completa

Una página armoniosa no necesita variables para cada píxel, pero sí necesita decisiones compartidas. Este ejemplo reúne valores que normalmente controlan la composición:

```css
:root {
  /* Espaciado */
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-3: 0.75rem;
  --space-4: 1rem;
  --space-5: 1.5rem;
  --space-6: 2rem;
  --space-7: 3rem;
  --space-8: 5rem;

  /* Lectura y proporción */
  --measure-body: 65ch;
  --measure-wide: 78rem;
  --line-body: 1.6;
  --line-heading: 1.1;

  /* Forma y superficie */
  --radius-small: 0.25rem;
  --radius-card: 0.75rem;
  --border-subtle: 1px solid #d7dee8;

  /* Tipografía */
  --text-small: 0.875rem;
  --text-body: 1rem;
  --text-lead: 1.25rem;
  --text-title: 3rem;
}
```

Estos valores son **tokens**: nombres que representan decisiones del sistema. Una tarjeta puede usar `--radius-card`, un texto auxiliar `--text-small` y una sección `--space-8` sin que cada componente invente su propia escala. La armonía no depende de que todos los elementos sean idénticos, sino de que sus diferencias sean intencionales.

No conviertas cada propiedad en una variable por obligación. `--button-padding-left-compact` puede ser una excepción local; `--space-3` expresa una relación que probablemente se reutilizará.

### Escala de tamaños de texto

El espaciado y la tipografía se influyen mutuamente. Un título grande necesita más aire alrededor, pero no necesariamente una línea de altura enorme:

```css
h1 {
  max-inline-size: 15ch;
  margin-block: 0 var(--space-5);
  font-size: var(--text-title);
  line-height: var(--line-heading);
}

.entradilla {
  max-inline-size: 55ch;
  margin-block: 0 var(--space-6);
  font-size: var(--text-lead);
  line-height: 1.45;
}

.metadatos {
  font-size: var(--text-small);
  line-height: 1.4;
}
```

`max-inline-size` evita que un título muy largo forme una franja difícil de leer. El límite `ch` depende aproximadamente del ancho de los caracteres de la fuente, por lo que expresa una medida de lectura y no una cantidad fija de píxeles.

## Ritmo vertical

El ritmo vertical es la repetición coherente de espacios y alturas de línea. Una escala pequeña de espaciado ayuda a que títulos, párrafos, listas y secciones se sientan relacionados.

```css
:root {
  --space-1: 0.5rem;
  --space-2: 1rem;
  --space-3: 1.5rem;
  --space-4: 2.5rem;
}

.articulo h2 {
  margin-block: var(--space-4) var(--space-2);
}

.articulo p + p {
  margin-block-start: var(--space-2);
}
```

El ritmo no exige que todas las distancias sean iguales. Una separación pequeña puede agrupar una etiqueta con su título, mientras una mayor separación puede indicar el inicio de una sección nueva.

### Cómo leer las distancias verticales

Piensa en tres niveles:

1. **Dentro de un componente**: el `padding` separa el contenido del borde.
2. **Entre elementos relacionados**: un título y su párrafo necesitan una distancia corta.
3. **Entre grupos diferentes**: dos secciones necesitan una distancia mayor para indicar un cambio.

```css
.tarjeta {
  padding: var(--space-5);
}

.tarjeta h2 {
  margin-block-end: var(--space-2);
}

.seccion + .seccion {
  margin-block-start: var(--space-7);
}
```

Si usas el mismo espacio grande entre el título y su párrafo y entre dos secciones, el lector no sabrá si esos elementos pertenecen al mismo grupo. El espaciado comunica estructura: poco espacio une; mucho espacio separa.

### `margin`, `padding` y `gap` en el ritmo

Estas propiedades no son intercambiables:

- `padding` crea espacio dentro de una caja y mueve su contenido sin separarla de sus vecinas;
- `margin` crea espacio fuera de una caja y la separa de otros elementos;
- `gap` separa de forma explícita a los hijos directos de un contenedor flex o grid.

```css
.perfil {
  padding: var(--space-5);
}

.perfil + .perfil {
  margin-block-start: var(--space-4);
}

.acciones {
  display: flex;
  gap: var(--space-2);
}
```

El modelo de caja completo, que explica por qué el `padding` afecta al interior y el `margin` al exterior, está en [2.3. Modelo de caja](../Modelo-en-caja/2.3-modelo-de-caja.md). Para grupos flex y grid, `gap` suele ser más predecible que colocar márgenes en cada hijo, como se introdujo en [3.2. `display`](3.2-display.md).

### Ritmo de texto y altura de línea

El espacio vertical no depende solo de `margin`. Si la altura de línea es demasiado pequeña, el texto se amontona; si es demasiado grande, cada párrafo parece fragmentado.

```css
.lectura {
  max-inline-size: 65ch;
  line-height: var(--line-body);
}

.lectura h1 {
  line-height: 1.1;
  margin-block-end: var(--space-4);
}

.lectura p {
  margin-block: 0 var(--space-4);
}
```

`max-inline-size: 65ch` limita la longitud aproximada de las líneas para que el ojo no tenga que recorrer una distancia excesiva. El valor exacto depende de la tipografía y del idioma; no es una regla matemática universal.

Para evitar márgenes enfrentados y colapso accidental, se puede usar `gap` en un contenedor flex o grid:

```css
.grupo-de-campos {
  display: grid;
  gap: 1rem;
}
```

## Proporción y alineación

La alineación crea relaciones claras entre los elementos. Un encabezado, un párrafo y una imagen pueden compartir un eje; una barra lateral puede tener un ancho estable mientras el contenido principal ocupa el espacio restante.

```css
.contenido {
  display: grid;
  grid-template-columns: 1fr 18rem;
  gap: 2rem;
  align-items: start;
}
```

La columna principal ocupa el espacio restante y la barra lateral mantiene un ancho definido. Las proporciones deben responder a la cantidad de contenido: una columna principal necesita más espacio que una barra auxiliar, pero ninguna debe ser tan estrecha que dificulte la lectura.

Las propiedades lógicas expresan el espaciado según el flujo de lectura:

```css
.tarjeta {
  padding-block: 1.5rem;
  padding-inline: 1rem;
  margin-block-end: 2rem;
}
```

Así, el mismo estilo funciona mejor en idiomas y modos de escritura distintos que si asumiera siempre las direcciones físicas arriba, derecha, abajo e izquierda.

### Proporción: cuánto espacio recibe cada zona

Una composición proporcionada no significa que todas las columnas tengan el mismo ancho. Significa que cada zona recibe el espacio que necesita para su función.

```css
.pagina {
  display: grid;
  grid-template-columns: 1fr 18rem;
  gap: var(--space-6);
  max-inline-size: 76rem;
  margin-inline: auto;
  padding-inline: var(--space-4);
}
```

La columna principal usa `1fr` para ocupar el espacio restante y la barra lateral tiene un ancho estable. La proporción debe justificar la función de cada zona: el contenido principal necesita más espacio para leer y la barra lateral debe ser suficientemente ancha para sus controles.

No elijas proporciones solo mirando una captura de pantalla. Prueba títulos largos, párrafos traducidos, controles con texto ampliado y contenido real. Una columna que se ve equilibrada con texto corto puede quedar inutilizable cuando el contenido cambia.

### Alinear bordes, no solo centros

En una página de lectura, suele ser más útil compartir el mismo inicio de línea que centrar cada bloque:

```css
.encabezado,
.contenido,
.pie {
  max-inline-size: 70ch;
  margin-inline: auto;
  padding-inline: var(--space-4);
}
```

El título, los párrafos y el pie comienzan en un mismo eje. Esa continuidad ayuda a recorrer la página con la mirada. Centrar todos los elementos puede parecer ordenado, pero dificulta la lectura de párrafos largos y oculta la jerarquía del contenido.

### Alineación en flex y grid

En flex, `justify-content` trabaja principalmente en el eje principal y `align-items` en el eje transversal. En grid, `justify-items` y `align-items` alinean el contenido dentro de sus celdas; `justify-content` y `align-content` pueden distribuir la cuadrícula completa dentro del contenedor.

```css
.barra {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: var(--space-3);
}
```

`gap` expresa la distancia entre elementos. `space-between` distribuye el espacio sobrante, por lo que la distancia real puede cambiar según el ancho disponible. Usa `gap` cuando necesites una separación mínima estable y `space-between` cuando quieras que los extremos se separen ocupando la fila.

## Espacio en blanco

El espacio en blanco es el área sin contenido que rodea o separa elementos. No es espacio desperdiciado: permite agrupar, separar, dar énfasis y hacer más fácil la lectura.

- Poco espacio entre elementos relacionados ayuda a percibirlos como un grupo.
- Más espacio entre grupos hace evidente el cambio de tema o sección.
- El espacio alrededor de texto mejora su legibilidad, siempre que la línea no sea demasiado ancha.
- Un espaciado consistente suele ser más importante que usar muchos valores diferentes.

No dependas de secuencias de espacios en el HTML para componer una página. Usa CSS para el espacio visual; reserva el contenido textual y su estructura para HTML.

### Espacio en blanco y jerarquía

El espacio en blanco funciona como signos de puntuación visuales:

- un `gap` pequeño equivale a elementos que forman una unidad;
- un `margin-block` mayor puede marcar el comienzo de otro bloque;
- el `padding` alrededor de una tarjeta crea un área de lectura protegida;
- un margen exterior amplio puede dar importancia a una sección.

```css
.filtros {
  display: flex;
  flex-wrap: wrap;
  gap: var(--space-2);
  padding: var(--space-4);
  margin-block-end: var(--space-6);
}

.resultado + .resultado {
  margin-block-start: var(--space-4);
}
```

Los filtros están juntos porque son controles del mismo grupo. El margen inferior separa ese grupo de los resultados. La separación entre resultados es menor que la separación entre filtros y resultados porque los resultados todavía pertenecen a la misma zona de contenido.

## Alineación visual y óptica

Una alineación matemáticamente exacta no siempre se percibe como equilibrada. Por ejemplo, un icono puede necesitar una corrección óptica pequeña respecto al texto. Primero establece una alineación consistente con flex o grid y luego aplica ajustes mínimos cuando haya una razón visual clara.

```css
.boton {
  display: inline-flex;
  align-items: center;
  gap: 0.5em;
}
```

`align-items` alinea los hijos en el eje transversal del contenedor flex; `gap` mantiene una distancia explícita entre ellos, sin depender de márgenes individuales.

### Alineación matemática frente a alineación percibida

La alineación matemática usa las cajas que calcula el navegador. La alineación visual considera cómo percibe una persona las formas, los pesos y los espacios. Dos cajas pueden tener el mismo centro geométrico y parecer descentradas porque:

- un icono tiene una forma irregular;
- las letras tienen una línea base distinta de la altura del icono;
- un botón tiene un borde o una sombra que cambia su peso visual;
- un bloque de texto tiene más “masa” en un lado.

Empieza siempre con una regla estructural y medible:

```css
.accion {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: var(--space-2);
  min-block-size: 2.75rem;
  padding-inline: var(--space-4);
}
```

Después observa el resultado con contenido real. Si el icono parece ligeramente bajo, un ajuste pequeño puede ser razonable:

```css
.accion svg {
  transform: translateY(-0.05em);
}
```

Este ajuste no debe sustituir a `align-items: center` ni convertirse en una colección de valores distintos para cada icono. Primero se resuelve la estructura con flexbox o grid; la corrección óptica es el último ajuste, no la base del layout.

### Alinear elementos de alturas distintas

En una fila de tarjetas, centrar verticalmente todo puede hacer que las líneas de acción queden a alturas diferentes. Si las tarjetas deben compararse, puede ser mejor usar una estructura interna que reserve zonas:

```css
.tarjetas {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: var(--space-4);
}

.tarjeta {
  display: grid;
  grid-template-rows: auto 1fr auto;
  gap: var(--space-3);
  padding: var(--space-5);
}
```

La fila central absorbe el espacio disponible y la acción final queda alineada entre tarjetas. Esto es una decisión de composición, no un problema que deba resolverse con `position: absolute` o con márgenes arbitrarios.

### Línea base en texto e iconos

Cuando un icono aparece junto a texto en línea, la línea base puede producir una sensación de desalineación:

```css
.enlace-icono {
  display: inline-flex;
  align-items: center;
  gap: 0.35em;
}
```

`inline-flex` mantiene el grupo dentro del texto, mientras `align-items: center` alinea sus hijos dentro de la caja. Si se usa un `inline-block` en lugar de flex, `vertical-align: middle` puede ser necesario, pero la decisión debe basarse en el comportamiento del componente, no en probar valores al azar.

## Jerarquía visual: decidir qué se ve primero

La composición no consiste solo en alinear cajas. También organiza la atención. Una persona suele percibir antes las diferencias grandes de tamaño, contraste, posición y espacio que los detalles pequeños.

Un orden útil para construir una página es:

1. **estructura**: define las zonas principales y sus relaciones;
2. **jerarquía**: decide qué título, acción o información debe destacar;
3. **ritmo**: asigna espacios entre niveles de la estructura;
4. **detalle**: ajusta bordes, iconos, radios y correcciones ópticas.

Si el botón principal, el título y una etiqueta secundaria tienen el mismo tamaño y el mismo contraste, el usuario no sabrá por dónde comenzar. No intentes corregirlo añadiendo más colores: prueba primero con tamaño, peso, posición y espacio.

```css
.pagina-titulo {
  margin-block-end: var(--space-2);
  font-size: 3rem;
  line-height: var(--line-heading);
}

.pagina-descripcion {
  max-inline-size: 60ch;
  margin-block-end: var(--space-6);
  color: #526173;
  font-size: var(--text-lead);
}

.accion-principal {
  min-block-size: 2.75rem;
  padding-inline: var(--space-5);
}
```

La descripción está limitada y separada del título, mientras la acción tiene una dimensión suficiente para reconocerse y activarse. No se usan coordenadas para fabricar esa jerarquía: el flujo normal y el espaciado expresan la relación.

## Componer una página por zonas

Una página completa suele necesitar un contenedor exterior, una columna de lectura y secciones. Es mejor resolver primero estas zonas que empezar ajustando tarjetas individuales.

```html
<main class="sitio">
  <section class="hero">
    <div class="contenedor">
      <p class="eyebrow">Guía práctica</p>
      <h1>Diseñar con espacio</h1>
      <p class="entradilla">Una composición clara ayuda a leer, comparar y actuar.</p>
    </div>
  </section>

  <section class="seccion">
    <div class="contenedor contenedor-lectura">
      <h2>Principios</h2>
      <p>El contenido principal comparte un eje y una medida de lectura.</p>
    </div>
  </section>
</main>
```

```css
.contenedor {
  inline-size: min(calc(100% - 2 * var(--space-4)), var(--measure-wide));
  margin-inline: auto;
}

.contenedor-lectura {
  max-inline-size: var(--measure-body);
}

.hero {
  padding-block: var(--space-8);
}

.seccion {
  padding-block: var(--space-7);
}
```

El contenedor exterior limita el ancho total y centra el contenido. La medida de lectura limita los párrafos. Las secciones tienen más espacio vertical que los elementos internos, así el lector percibe un cambio de zona.

`calc()` permite combinar unidades y variables; su uso se relaciona con [2.6. Funciones CSS](../Modelo-en-caja/2.6-funciones-css.md). El `padding` y el `margin` forman parte del modelo de caja explicado en [2.3. Modelo de caja](../Modelo-en-caja/2.3-modelo-de-caja.md): el primero protege el contenido dentro de la sección y el segundo centra o separa la caja respecto a otras.

## Patrones de espaciado para componentes reales

### Tarjetas

Una tarjeta debe tener suficiente espacio interior para que su contenido respire, pero no tanto que pierda unidad. El espacio entre tarjetas pertenece al contenedor, no a la decoración interna.

```css
.lista-tarjetas {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: var(--space-5);
}

.tarjeta {
  display: grid;
  gap: var(--space-3);
  padding: var(--space-5);
  border: var(--border-subtle);
  border-radius: var(--radius-card);
}

.tarjeta h3,
.tarjeta p {
  margin: 0;
}
```

Las tres columnas mantienen una proporción común para comparar tarjetas. `gap` separa tarjetas; `padding` separa el contenido del borde. Restablecer los márgenes internos evita que el navegador añada separaciones inesperadas encima de la separación que ya controla la tarjeta.

### Formularios

En un formulario, la etiqueta, el campo y el mensaje de ayuda forman grupos. La distancia entre grupos debe ser mayor que la distancia interna de cada grupo:

```html
<form class="formulario">
  <div class="campo">
    <label for="email">Correo electrónico</label>
    <input id="email" type="email" aria-describedby="email-ayuda">
    <p id="email-ayuda" class="ayuda">Usaremos este correo para responderte.</p>
  </div>

  <button type="submit">Enviar</button>
</form>
```

```css
.formulario {
  display: grid;
  gap: var(--space-5);
  max-inline-size: 32rem;
}

.campo {
  display: grid;
  gap: var(--space-2);
}

.campo label {
  font-weight: 700;
}

.campo input {
  min-block-size: 2.75rem;
  padding-inline: var(--space-3);
}

.ayuda {
  margin: 0;
  color: #526173;
  font-size: var(--text-small);
}
```

El `gap` pequeño une la etiqueta con su campo y ayuda; el `gap` mayor separa un campo del siguiente. El mensaje de ayuda no debe depender de un color tenue o un tamaño ilegible para desaparecer: su espacio y contraste forman parte de la comprensión del formulario.

### Navegación y barras de acciones

Una barra de acciones necesita una alineación estable cuando hay espacio y debe poder envolverse cuando no lo hay:

```css
.acciones {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: var(--space-2);
}

.acciones-principales {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  gap: var(--space-4);
  padding-block: var(--space-4);
  border-block: var(--border-subtle);
}
```

`flex-wrap` permite que los botones formen varias líneas dentro de la barra cuando el contenido lo exige. No uses `position: absolute` para fijar acciones a una coordenada: el texto puede crecer, como se explicó al estudiar [3.3. `position`](3.3-position.md).

## Densidad: no todo debe tener el mismo aire

Una interfaz puede ser espaciosa, compacta o mixta. Una tabla de datos necesita mostrar muchas filas; una página editorial necesita pausas amplias para facilitar la lectura. La armonía no significa usar `2rem` en todas partes.

```css
.tabla-datos {
  --row-padding: var(--space-2);
}

.tabla-datos td,
.tabla-datos th {
  padding-block: var(--row-padding);
  padding-inline: var(--space-3);
}

.panel-editorial {
  padding-block: var(--space-7);
}
```

El token local `--row-padding` permite que la tabla sea más densa sin alterar el ritmo general de la página. El panel editorial conserva una pausa más amplia. Las diferencias deben responder al trabajo de la persona: leer, comparar, editar o explorar.

Evita la densidad accidental: texto pequeño, controles apretados y ausencia de espacios no crean una interfaz profesional; solo aumentan el esfuerzo visual.


## Qué hacer cuando la página se siente desordenada

No empieces cambiando colores o añadiendo sombras. Haz este diagnóstico:

1. **Busca el eje principal**: ¿qué elementos deberían comenzar en la misma línea?
2. **Mide la lectura**: ¿los párrafos son demasiado anchos o estrechos?
3. **Clasifica cada espacio**: ¿es `padding`, `margin` o `gap`? ¿Está expresando la relación correcta?
4. **Encuentra excepciones**: ¿hay muchos valores como `13px`, `19px` y `27px` que podrían pertenecer a una escala?
5. **Revisa la jerarquía**: ¿el título, la información y la acción principal tienen diferencias claras?
6. **Prueba contenido difícil**: títulos largos, traducciones, errores, campos vacíos e imágenes faltantes.
7. **Revisa los bordes**: una caja puede parecer mal alineada por su borde, sombra o radio aunque su contenido esté correctamente colocado.

Una técnica útil es añadir temporalmente fondos distintos a cada nivel:

```css
main { background: rgb(239 246 255 / 0.4); }
section { background: rgb(240 253 250 / 0.4); }
article { background: rgb(255 247 237 / 0.5); }
```

Si no puedes explicar por qué existe una separación, una alineación o una anchura, probablemente esa regla necesita simplificarse o recibir un nombre dentro del sistema.

## Comprobar la composición

Revisa la página con contenido real:

1. Comprueba que títulos, texto y controles compartan alineaciones intencionales.
2. Observa si el espacio distingue grupos sin separar elementos relacionados.
3. Prueba cadenas largas, traducciones y texto ampliado.
4. Comprueba que las proporciones y alineaciones respondan al contenido.
5. Ajusta el ritmo con una escala pequeña en vez de acumular excepciones.

### Método de revisión

Una revisión útil puede hacerse en cuatro pasadas:

1. **Estructura**: comprueba que el HTML agrupe elementos que realmente pertenecen juntos.
2. **Espaciado**: identifica si cada distancia corresponde a interior, separación entre hermanos o separación entre secciones.
3. **Alineación**: marca los ejes compartidos y decide cuáles son intencionales.
4. **Percepción**: observa iconos, bordes, sombras y masas de texto; aplica correcciones ópticas pequeñas solo si la estructura ya es correcta.

Prueba al menos estos casos:

- un título de dos o tres líneas;
- un párrafo largo;
- una traducción más extensa;
- zoom del navegador o texto aumentado;
- un elemento sin imagen o con una imagen de proporción diferente.

Si el diseño solo funciona con el contenido exacto del ejemplo, no tiene una composición robusta: tiene una composición ajustada a una captura.

La composición debe apoyar la jerarquía y la lectura. Si una regla de espaciado oculta contenido o dificulta el uso, la prioridad es corregir la experiencia, no conservar la simetría visual.

## En resumen

- El ritmo vertical se construye con una escala coherente y jerarquías claras.
- `gap` funciona bien para separar los hijos de contenedores flex y grid.
- La alineación y las proporciones deben responder al contenido y al espacio asignado.
- El espacio en blanco organiza la información y también es parte del diseño.
- Las variables definidas en `:root` permiten mantener una escala de espaciado coherente.
- La alineación visual se construye primero con layout; los ajustes ópticos deben ser pequeños y justificados.
- Comprueba la composición en condiciones reales, no solo con el texto de ejemplo.
