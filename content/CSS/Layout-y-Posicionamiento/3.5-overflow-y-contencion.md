# 3.5. Overflow y contención

El contenido puede ser más grande que la caja que lo contiene. La propiedad `overflow` define qué sucede cuando ese contenido rebasa los límites, y las herramientas de contención ayudan a que una interfaz mantenga límites claros.

## Valores de `overflow`

```css
.panel {
  overflow: auto;
}
```

| Valor | Comportamiento |
|---|---|
| `visible` | El contenido puede dibujarse fuera de la caja. Es el valor inicial habitual. |
| `hidden` | Recorta el contenido que sale de la caja y permite desplazamiento programático, pero no muestra barras para desplazarlo manualmente. |
| `clip` | Recorta el contenido sin crear un contenedor de desplazamiento. |
| `scroll` | Crea un mecanismo de desplazamiento, aunque no siempre se vean las barras según el sistema operativo. |
| `auto` | Permite desplazamiento cuando el contenido lo necesita. |

Para que una caja se convierta en un área con desplazamiento, normalmente necesita una dimensión limitada en el eje correspondiente:

```css
.lista {
  max-block-size: 18rem;
  overflow-y: auto;
}
```

El contenido adicional se puede recorrer sin hacer crecer indefinidamente el componente.

## Ejes horizontal y vertical

Se pueden controlar los ejes por separado con `overflow-x` y `overflow-y`, o usar propiedades lógicas como `overflow-inline` y `overflow-block`.

```css
.tabla-contenida {
  overflow-x: auto;
}
```

Esto puede ser útil para una tabla ancha. Evita añadir desplazamiento horizontal a toda la página cuando basta con contenerlo alrededor del componente.

Combinar valores distintos en cada eje puede tener interacciones definidas por CSS: ciertos valores pueden computarse como `auto` o `hidden` cuando el otro eje crea un contenedor de desplazamiento. Si el resultado sorprende, inspecciona los valores computados en las herramientas de desarrollo.

## Truncar texto con `text-overflow`

`text-overflow` controla cómo se indica que una línea de texto se recortó, pero no recorta por sí misma el contenido. Para una elipsis en una sola línea, normalmente se combinan varias propiedades:

```css
.nombre-archivo {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

La caja necesita un ancho o una restricción equivalente para que el texto no se expanda sin límite.

Para varias líneas, se puede considerar `line-clamp` donde sea apropiado y compatible con los navegadores objetivo:

```css
.resumen {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  overflow: hidden;
}
```

No trunques contenido esencial sin ofrecer una forma de consultarlo completo. Comprueba también cómo se comporta con texto ampliado, traducciones y tecnologías de asistencia.

## Desplazamiento y experiencia de uso

`overflow: auto` puede crear un área que se desplaza de manera independiente a la página. En interfaces táctiles, `overscroll-behavior` permite controlar si el desplazamiento se propaga a los contenedores superiores:

```css
.panel-desplazable {
  max-block-size: 20rem;
  overflow: auto;
  overscroll-behavior: contain;
}
```

Usa esta propiedad con cuidado: impedir toda propagación puede hacer que la navegación por desplazamiento se sienta atrapada.

## Contener trabajo de layout y pintura

La propiedad `contain` permite declarar que ciertas operaciones de layout, estilo, pintura o tamaño de un elemento están contenidas. Puede ayudar a limitar efectos entre partes independientes de una página, pero no es una solución genérica para recortar contenido ni para acelerar cualquier diseño.

```css
.widget-independiente {
  contain: layout paint;
}
```

El valor `paint` recorta la pintura al área de contención y puede cambiar cómo se muestran sombras o elementos posicionados. `layout` y `size` también tienen efectos sobre la composición y el tamaño. Añade contención solo cuando el comportamiento deseado esté claro y se haya comprobado el resultado.

## En resumen

- `overflow` define qué ocurre cuando el contenido excede una caja.
- `auto` es una opción habitual para áreas que pueden necesitar desplazamiento.
- `text-overflow: ellipsis` requiere además una caja limitada y control del desbordamiento.
- Diseña las áreas desplazables y el texto truncado teniendo en cuenta accesibilidad y uso táctil.
- `contain` afecta al cálculo o a la pintura; no es sinónimo de `overflow`.
