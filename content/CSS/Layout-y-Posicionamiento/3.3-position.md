# 3.3. `position`

La propiedad `position` controla cómo se coloca una caja respecto al flujo normal y qué referencias puede usar con propiedades como `top`, `right`, `bottom` y `left` (o sus equivalentes lógicos).

```css
.elemento {
  position: relative;
  inset-block-start: 0.5rem;
  inset-inline-start: 1rem;
}
```

Las propiedades de inset indican desplazamientos desde los lados de referencia. Si no se definen, el elemento conserva su ubicación determinada por el layout.

## `static`: el comportamiento por defecto

La mayoría de los elementos usan `position: static`. Participan en el flujo normal y las propiedades `top`, `right`, `bottom`, `left` e `inset` no los desplazan.

```css
.tarjeta {
  position: static;
}
```

No hace falta escribir `position: static` salvo que se esté restableciendo un estilo anterior.

## `relative`: desplazar sin perder el espacio original

Un elemento con `position: relative` conserva su lugar en el flujo. Los insets lo desplazan visualmente desde su posición original, pero los demás elementos siguen reservando el espacio que ocupaba antes del desplazamiento.

```css
.etiqueta {
  position: relative;
  inset-block-start: 0.25rem;
}
```

También es común usar `relative` sin desplazamiento para establecer un bloque de referencia para un descendiente absoluto:

```html
<article class="tarjeta">
  <h2>Noticia</h2>
  <span class="estado">Nuevo</span>
</article>
```

```css
.tarjeta {
  position: relative;
}

.estado {
  position: absolute;
  inset-block-start: 1rem;
  inset-inline-end: 1rem;
}
```

## `absolute`: fuera del flujo normal

Un elemento con `position: absolute` no reserva su espacio en el flujo. Se posiciona con respecto a su bloque contenedor, que suele ser el ancestro más cercano que establece el bloque de referencia para elementos posicionados. Un ancestro con `position` distinto de `static` es el caso más habitual; algunas propiedades, como `transform`, también pueden establecer una referencia.

Si no se encuentra un ancestro adecuado, la referencia suele ser el bloque contenedor inicial. Por eso es importante revisar la cadena de ancestros cuando un elemento absoluto aparece en un lugar inesperado.

Usa `absolute` para detalles superpuestos y acotados a un componente, no como método general para construir una página. Al salir del flujo, no empuja a los demás elementos y puede solaparse con ellos.

## `fixed`: anclado a la ventana o a un ancestro especial

`position: fixed` suele fijar el elemento respecto al viewport, de modo que permanece en la misma posición durante el desplazamiento de la página.

```css
.boton-ayuda {
  position: fixed;
  inset-block-end: 1rem;
  inset-inline-end: 1rem;
}
```

Un ancestro con ciertas propiedades, como `transform`, puede cambiar el bloque de referencia de un elemento fijo. Si no se comporta como si estuviera anclado a la ventana, inspecciona sus ancestros.

Los elementos fijos pueden cubrir contenido, especialmente en pantallas pequeñas. Comprueba que no oculten controles y que el contenido siga siendo accesible con zoom y desplazamiento.

## `sticky`: flujo normal con un límite de desplazamiento

`position: sticky` se comporta como un elemento en flujo normal hasta que alcanza un umbral de inset durante el desplazamiento. Entonces queda adherido dentro de su contenedor de desplazamiento.

```css
.encabezado-seccion {
  position: sticky;
  inset-block-start: 0;
  z-index: 1;
  background: white;
}
```

Para que se note el efecto, normalmente debe especificarse al menos un inset en el eje donde se espera el desplazamiento. Además:

- el elemento sigue ocupando espacio en el flujo;
- se mantiene dentro de los límites de su contenedor;
- un ancestro con `overflow` puede convertirse en el contenedor de desplazamiento relevante;
- el contenedor debe permitir suficiente desplazamiento para que exista espacio donde adherirse.

## Posicionamiento y `z-index`

`z-index` puede establecer el orden de apilamiento de elementos en los contextos donde aplica. Es habitual usarlo con elementos posicionados, y también funciona con elementos flex y grid. Sin embargo, un número alto no permite escapar de un contexto de apilamiento creado por un ancestro.

El detalle de los contextos y el orden de pintura se explica en [3.4. Contexto de apilamiento](3.4-contexto-de-apilamiento.md).

## En resumen

- `static` participa en el flujo sin desplazamientos.
- `relative` conserva el espacio original y puede servir como referencia para descendientes.
- `absolute` sale del flujo y se ubica respecto a un bloque contenedor.
- `fixed` suele referirse al viewport; `sticky` conserva su lugar y se adhiere dentro de un contenedor.
- Usa posicionamiento para relaciones espaciales concretas, no para reemplazar el layout normal.
