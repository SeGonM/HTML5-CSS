# 2.3. Modelo de caja

Cada elemento visible se representa como una caja compuesta por contenido, `padding`, borde y margen.

```text
┌──────────── margen ────────────┐
│ ┌──────────── borde ─────────┐ │
│ │ ┌──────── padding ───────┐ │ │
│ │ │       contenido        │ │ │
│ │ └────────────────────────┘ │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
```

La caja es la unidad básica del diseño en CSS. Todo lo que vemos — un párrafo, una tarjeta, un botón, un menú, una imagen termina representado como una caja rectangular con dimensiones, relleno, borde y espacio exterior.

Para entender diseño web, es esencial comprender que cada elemento tiene dos tipos de espacio:

- espacio interior: `padding`;
- espacio exterior: `margin`.

Estas dos propiedades parecen simples, pero determinan casi toda la composición visual de una página.

## 1. ¿Qué es el `padding`?

El `padding` es el espacio que existe entre el contenido del elemento y su borde. Es “relleno” interno.

```css
.card {
  padding: 1rem;
}
```

Esto significa: dentro de la tarjeta, hay 1rem de espacio alrededor del texto o contenido.

### Ejemplo visual

```html
<div class="card">
  <p>Este texto tiene espacio interior.</p>
</div>
```

```css
.card {
  background: #f3f4f6;
  border: 1px solid #d1d5db;
  padding: 1rem;
}
```

El texto no está pegado al borde; queda separado por el relleno.

### El padding afecta el tamaño visible

Si un elemento tiene `width: 200px` y `padding: 20px`, el contenido ocupa menos de 200px, porque el relleno consume parte del espacio interior.

Eso es por eso que CSS tiene el concepto de `box-sizing`:

- `content-box` (por defecto): ancho = contenido + padding + borde;
- `border-box`: el ancho declarado ya incluye padding y borde.

## 2. Las 4 propiedades del `padding`

El padding se puede definir de cuatro formas específicas:

- `padding-top`
- `padding-right`
- `padding-bottom`
- `padding-left`

### Ejemplo individual

```css
.card {
  padding-top: 1rem;
  padding-right: 1.5rem;
  padding-bottom: 2rem;
  padding-left: 1rem;
}
```

Esto se interpreta así:

- arriba: `1rem`
- derecha: `1.5rem`
- abajo: `2rem`
- izquierda: `1rem`

### Orden visual de las direcciones

En CSS, las direcciones se suelen pensar así:

```text
      top
left     right
      bottom
```

Cuando escribes padding, la lógica sigue este sentido:

- arriba
- derecha
- abajo
- izquierda

## 3. Forma abreviada del `padding`

La forma abreviada permite escribir varias propiedades en una sola línea.

### 1 valor

```css
.card {
  padding: 1rem;
}
```

Esto aplica `1rem` a los cuatro lados.

### 2 valores

```css
.card {
  padding: 1rem 2rem;
}
```

Interpretación:

- `1rem` = arriba y abajo
- `2rem` = izquierda y derecha

### 3 valores

```css
.card {
  padding: 1rem 2rem 3rem;
}
```

Interpretación:

- `1rem` = arriba
- `2rem` = izquierda y derecha
- `3rem` = abajo

### 4 valores

```css
.card {
  padding: 1rem 2rem 3rem 4rem;
}
```

Interpretación:

- `1rem` = arriba
- `2rem` = derecha
- `3rem` = abajo
- `4rem` = izquierda

Es decir, el orden es siempre:

```css
padding: arriba derecha abajo izquierda;
```

### Ejemplo claro

```css
.card {
  padding: 12px 20px 16px 8px;
}
```

Esto equivale a:

```css
.card {
  padding-top: 12px;
  padding-right: 20px;
  padding-bottom: 16px;
  padding-left: 8px;
}
```

## 4. ¿Qué es el `margin`?

El `margin` es el espacio exterior del elemento: el espacio que existe fuera de su borde, respecto a otros elementos vecinos.

Mientras `padding` separa el contenido del borde, `margin` separa la caja de otras cajas.

```css
.card {
  margin: 1.5rem;
}
```

Esto hace que la tarjeta se separe del resto de elementos alrededor.

### Ejemplo

```html
<div class="caja1"></div>
<div class="caja2"></div>
```

```css
.caja1 {
  background: #dbeafe;
  height: 80px;
  margin-bottom: 1rem;
}

.caja2 {
  background: #dcfce7;
  height: 80px;
}
```

La primera caja crea espacio debajo de sí misma, separando a la segunda.

## 5. Las 4 propiedades del `margin`

Al igual que con `padding`, hay cuatro propiedades individuales:

- `margin-top`
- `margin-right`
- `margin-bottom`
- `margin-left`

### Ejemplo

```css
.card {
  margin-top: 0.5rem;
  margin-right: 1rem;
  margin-bottom: 1.5rem;
  margin-left: 2rem;
}
```

Esto significa:

- arriba: `0.5rem`
- derecha: `1rem`
- abajo: `1.5rem`
- izquierda: `2rem`

## 6. Forma abreviada del `margin`

La abreviatura sigue la misma lógica que `padding`.

### 1 valor

```css
.card {
  margin: 1rem;
}
```

Esto aplica `1rem` a los cuatro lados.

### 2 valores

```css
.card {
  margin: 1rem 2rem;
}
```

Interpretación:

- arriba y abajo: `1rem`
- izquierda y derecha: `2rem`

### 3 valores

```css
.card {
  margin: 1rem 2rem 3rem;
}
```

Interpretación:

- arriba: `1rem`
- izquierda y derecha: `2rem`
- abajo: `3rem`

### 4 valores

```css
.card {
  margin: 1rem 2rem 3rem 4rem;
}
```

Interpretación:

- arriba: `1rem`
- derecha: `2rem`
- abajo: `3rem`
- izquierda: `4rem`

### Orden clave

La regla más importante es:

```css
margin: arriba derecha abajo izquierda;
```

## 7. Diferencia práctica entre `margin` y `padding`

Esta es una de las confusiones más frecuentes al empezar.

### `padding`

Se usa para crear aire dentro del elemento.

```css
button {
  padding: 0.75rem 1rem;
}
```

Esto hace que el texto del botón no esté pegado al borde del botón.

### `margin`

Se usa para crear aire fuera del elemento.

```css
button {
  margin: 1rem;
}
```

Esto separa el botón de otros elementos alrededor.

### Ejemplo visual

```html
<div class="contenedor">
  <button class="boton">Enviar</button>
</div>
```

```css
.contenedor {
  border: 1px solid #ccc;
}

.boton {
  padding: 0.75rem 1rem;
  margin: 1rem;
}
```

- `padding` crea aire dentro del botón;
- `margin` crea aire fuera del botón, separándolo del contenedor.

## 8. Ejemplo completo con todas las formas

### Variante con propiedades individuales

```css
.card {
  margin-top: 1rem;
  margin-right: 2rem;
  margin-bottom: 3rem;
  margin-left: 4rem;

  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 30px;
  padding-left: 40px;
}
```

### Variante abreviada equivalente

```css
.card {
  margin: 1rem 2rem 3rem 4rem;
  padding: 10px 20px 30px 40px;
}
```

Ambas formas producen el mismo resultado.

## 9. El orden en sentido horario

El truco para no confundirse es recordar esta frase:

> “arriba, derecha, abajo, izquierda”

Es decir, en sentido horario empezando desde arriba.

```css
margin: 10px 20px 30px 40px;
```

se lee así:

- 10px → arriba
- 20px → derecha
- 30px → abajo
- 40px → izquierda

Esto se aplica igual a `padding` y a las cuatro propiedades individuales.

## 10. ¿Qué pasa si pones menos valores?

CSS tiene reglas de atajo muy útiles:

### `margin: 10px`

Todos los lados tienen `10px`.

### `margin: 10px 20px`

- arriba y abajo: `10px`
- izquierda y derecha: `20px`

### `margin: 10px 20px 30px`

- arriba: `10px`
- izquierda y derecha: `20px`
- abajo: `30px`

### `margin: 10px 20px 30px 40px`

- arriba: `10px`
- derecha: `20px`
- abajo: `30px`
- izquierda: `40px`

Lo mismo aplica a `padding`.

## 11. Margen automático

El `margin` también puede tomar valores especiales como `auto`.

```css
.caja {
  width: 500px;
  margin-inline: auto;
}
```

Esto centra el elemento horizontalmente dentro de su contenedor.

También puedes hacer esto:

```css
.card {
  margin: 0 auto;
}
```

Esto suele utilizarse para centrar bloques con ancho fijo.

## 12. Margen colapsable

Un detalle importante del `margin` es que los márgenes verticales de algunos elementos pueden colapsar.

```html
<div class="padre">
  <div class="hijo">Texto</div>
</div>
```

```css
.padre {
  background: #eee;
}

.hijo {
  margin-top: 2rem;
}
```

A veces el margen del hijo se “fusiona” con el margen del padre, y no se suman como podrías esperar. Esto se conoce como margen colapsable.

Es un comportamiento especial de los elementos en bloque en flujo normal. No ocurre siempre, pero es importante saber que existe.

Para evitar este tipo de conflictos se usa a menudo:

- `padding` en el padre;
- `border` en el padre;
- `display: flow-root;`;
- `gap` en flex/grid;
- o simplemente establecer el espaciado de manera más controlada.

## 13. Recomendaciones prácticas

- usa `padding` para crear aire dentro del elemento;
- usa `margin` para crear separación entre elementos;
- evita poner margen en todos lados cuando necesitas distancia solo en una dirección;
- usa abreviaturas cuando el patrón sea claro;
- para diseños complejos, intenta ser explícito con los lados que necesitas.

## 14. Resumen clave

El `padding` y el `margin` son dos espacios distintos pero muy relacionados:

- `padding`: dentro de la caja;
- `margin`: fuera de la caja.

Y la abreviatura sigue este orden:

```css
margin: arriba derecha abajo izquierda;
padding: arriba derecha abajo izquierda;
```

Así que esta forma:

```css
padding: 0 0 0 0;
```

es literalmente:

- arriba: `0`
- derecha: `0`
- abajo: `0`
- izquierda: `0`

Y lo mismo con `margin`.

Entender esta lógica te va a ayudar muchísimo a construir layouts claros, con espaciado limpio y controlado.
