# 2.5. Colores y fondos

El color es uno de los elementos más importantes del diseño visual. No solo da estilo; también comunica estados, jerarquía, tono emocional y contraste. Un buen uso del color hace que la interfaz sea clara, legible y coherente.

En CSS no solo puedes cambiar el color del texto: también puedes definir el fondo, el borde, el resaltado, los estados de interacción y las transiciones visuales.

## 1. El color como herramienta de diseño

Los colores ayudan a:

- diferenciar acciones importantes;
- indicar estados como éxito, error o advertencia;
- crear jerarquía entre elementos;
- mantener consistencia visual en un sistema de diseño;
- mejorar la legibilidad y el contraste.

Pero no debe ser la única forma de comunicar información. Si un botón es rojo, también debe haber texto claro o un icono que indique su propósito. El color debe acompañar a la semántica, no reemplazarla.

## 2. Sistemas de color más usados

CSS permite trabajar con varios formatos de color. Los más comunes en proyectos reales son estos:

### Hexadecimal

```css
.button {
  color: #2563eb;
  background: #eff6ff;
}
```

El formato hexadecimal se usa mucho porque es compacta y muy común en diseño web.

Ejemplo:

- `#fff` = blanco
- `#000` = negro
- `#2563eb` = un azul muy usado

### `rgb()` y `rgba()`

```css
.card {
  background: rgb(17 24 39);
  border: 1px solid rgb(148 163 184 / 0.5);
}
```

La sintaxis moderna permite valores separados por espacios y alfa con `/`:

```css
.panel {
  background: rgb(15 23 42 / 0.8);
}
```

Esto es muy cómodo porque permite controlar la transparencia directamente.

### `hsl()` y `hsla()`

```css
.badge {
  background: hsl(220 80% 60%);
  color: hsl(0 0% 100%);
}
```

`hsl()` usa:

- hue: tono (0 a 360)
- saturation: saturación
- lightness: luminosidad

Es muy útil si quieres crear paletas armoniosas, porque puedes variar el tono manteniendo la misma sensación visual.

### `oklch()`

```css
:root {
  --brand: oklch(62% 0.18 250);
  --brand-strong: oklch(50% 0.22 250);
}
```

`oklch()` es muy potente porque genera escalas más perceptualmente uniformes, lo que suele dar resultados más naturales y consistentes al ojo humano.

Es especialmente útil cuando quieres construir una paleta más sofisticada, con mejor contraste y coherencia visual.

## 3. `color-mix()`: mezclar colores de manera inteligente

```css
:root {
  --brand: oklch(55% 0.18 250);
  --brand-soft: color-mix(in srgb, var(--brand) 75%, white);
}
```

`color-mix()` permite mezclar dos colores entre sí en una proporción determinada.

Esto sirve para:

- crear tonos más claros u oscuros;
- generar variantes de un color base;
- mantener consistencia visual sin crear demasiadas variables manuales.

Ejemplo:

```css
.button {
  background: color-mix(in srgb, var(--brand) 80%, white 20%);
}
```

Eso produce una mezcla útil para hover o estados interactivos.

## 4. `color()` y espacios de color

```css
.accent {
  color: color(display-p3 0.2 0.55 0.9);
}
```

Esto usa un espacio de color concreto, como `display-p3`, cuando el navegador y el dispositivo lo soportan.

Es una opción interesante para gráficos o sistemas más avanzados, aunque en proyectos normales no suele ser imprescindible.

## 5. Paletas y variables

La forma más limpia de trabajar con colores es definir variables en `:root`:

```css
:root {
  --bg: #f8fafc;
  --surface: #ffffff;
  --text: #0f172a;
  --primary: #2563eb;
  --primary-strong: #1d4ed8;
  --success: #16a34a;
  --warning: #f59e0b;
  --danger: #dc2626;
}
```

Y luego usarlas:

```css
.card {
  background: var(--surface);
  color: var(--text);
}

.button-primary {
  background: var(--primary);
  color: white;
}
```

Esto ayuda a:

- mantener coherencia;
- cambiar la identidad visual más fácilmente;
- reutilizar paletas en todo el proyecto;
- reducir repeticiones innecesarias.

## 6. Contraste: la parte más importante del color

Un color bonito no sirve si no es legible. El contraste es un criterio clave para interfaces accesibles.

Ejemplo:

```css
.texto {
  color: #111827;
  background: #f9fafb;
}
```

Esto tiene mejor legibilidad que texto claro sobre fondo claro, o texto oscuro sobre fondo muy oscuro.

Regla simple:

- el texto debe contrastar bien con su fondo;
- los botones y enlaces deben ser legibles;
- los estados de error, éxito y advertencia no deben depender solo del color.

## 7. Fondos de color

La forma más básica es definir un color de fondo con `background-color`:

```css
.banner {
  background-color: #102a43;
  color: white;
}
```

Eso hace que el bloque tenga un color sólido.

### Cuándo usar fondos sólidos

- secciones con contenido textual claro;
- tarjetas con una identidad visual estable;
- bloques de información donde quieres un fondo uniforme;
- estados como success, warning, error.

## 8. Gradientes

Los gradientes son fondos que mezclan dos o más colores en una transición suave. Son más ricos visualmente que un fondo sólido y suelen usarse para crear profundidad o dinamismo.

### Gradiente lineal

```css
.linear {
  background: linear-gradient(135deg, #2563eb, #7c3aed);
}
```

Esto crea una transición diagonal de azul a morado.

### Gradiente radial

```css
.radial {
  background: radial-gradient(circle at top, #ffffff, #dbeafe 60%, #bfdbfe);
}
```

Esto crea una transición desde el centro o desde un punto específico hacia los extremos.

### Gradiente con múltiples paradas

```css
.hero {
  background: linear-gradient(120deg, #0f172a 0%, #1e3a8a 45%, #7c3aed 100%);
}
```

Esto da un efecto más avanzado y suele verse muy bien en banners o cabeceras.

## 9. Cómo elegir buen color para fondos y texto

Cuando usas un gradiente, siempre piensa en la legibilidad:

```css
.hero {
  background: linear-gradient(135deg, #111827, #312e81);
  color: #f8fafc;
}
```

El texto debe tener buen contraste sobre el fondo. Si usas un fondo intenso, el texto debe ser claro.

Si usas un fondo claro, el texto debe ser oscuro.

## 10. Usos muy comunes de gradientes

Los gradientes se usan mucho para:

- hero sections;
- botones con estilo premium;
- tarjetas destacadas;
- overlays o capas de fondo decorativas;
- interfaces más modernas y menos planas.

Pero no tienen que usarse por todas partes. Un sitio 100% con gradientes intensos puede resultar poco serio o poco legible. Lo mejor es usarlos con criterio.

## 11. Fondos con capas de color

Puedes combinar varios fondos usando capas de color o gradiente:

```css
.panel {
  background:
    linear-gradient(135deg, rgb(37 99 235 / 0.9), rgb(124 58 237 / 0.9)),
    #0f172a;
}
```

La primera capa se dibuja encima de la segunda. Esto permite mezclar un degradado con un color base de respaldo.

## 12. Recursos útiles

Estos sitios son muy prácticos para trabajar con colores y gradientes:

- https://htmlcolorcodes.com/
- https://cssgradient.io/

### ¿Para qué sirven?

- `htmlcolorcodes.com`: te ayuda a explorar paletas, tono, HEX, RGB y armonías de color.
- `cssgradient.io`: genera gradientes de manera visual y te devuelve el CSS listo para copiar.

Estos recursos son excelentes para experimentar sin memorizar demasiada teoría.

## 13. Recomendaciones prácticas

- define una paleta base con variables;
- usa colores con intención, no solo por gusto;
- asegúrate de que haya contraste suficiente;
- usa gradientes con moderación;
- combina fondo sólido + texto claro o fondo claro + texto oscuro;
- no te bases solo en color para comunicar significado.

## 14. Resumen

Los colores y fondos son parte central del diseño visual de una página. Los más usados son:

- hexadecimal;
- `rgb()` / `rgba()`;
- `hsl()` / `hsla()`;
- `oklch()`;
- `color-mix()`;
- gradientes lineales y radiales.

La clave es elegir un sistema que te ayude a mantener consistencia y accesibilidad. En la práctica, usar variables y paletas bien definidas es la mejor forma de evitar caos visual.
