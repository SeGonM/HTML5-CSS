# 2.6. Funciones CSS

Las funciones CSS son una de las herramientas más poderosas del lenguaje. Son como pequeñas instrucciones que dicen: “toma este valor, cálcalo, combínalo, toma el menor o el mayor, o consulta algo desde el entorno”.

Si las propiedades son los ingredientes y los valores son las cantidades, las funciones son las operaciones que te permiten mezclar, ajustar y adaptar esos valores con lógica.

Sin funciones, CSS sería muy rígido. Con funciones, puedes hacer cosas como:

- restar un padding a un ancho completo;
- limitar un texto para que nunca sea demasiado grande ni demasiado pequeño;
- reutilizar colores y medidas en todo el proyecto;
- adaptarte a la ventana del navegador y a los dispositivos modernos;
- mezclar colores sin crear variables infinitas.

## 1. ¿Qué es una función CSS?

Una función CSS se escribe como:

```css
nombre(argumentos)
```

Ejemplos:

```css
calc(100% - 2rem)
min(40rem, 100%)
var(--primary-color)
clamp(1rem, 2vw, 3rem)
```

La función no “genera un estilo por sí sola”; más bien devuelve un valor que luego usa otra propiedad CSS.

Por ejemplo:

```css
width: calc(100% - 2rem);
```

Aquí `calc()` devuelve un ancho calculado a partir de `100%` y `2rem`, y ese valor se lo aplica a `width`.

### Analogía útil

Imagina que CSS es como una cocina. Las propiedades son los platos, y las funciones son las herramientas de preparación: medir, mezclar, cortar, ajustar, adaptar. Sin herramientas, solo podrías usar ingredientes ya listos. Con funciones, puedes combinar y transformar lo que tienes.

## 2. `calc()`: la función más importante para operar con medidas

`calc()` permite combinar valores con operadores matemáticos. Es ideal para situaciones donde la ecuación real importa.

```css
.content {
  width: calc(100% - 2rem);
  min-height: calc(100dvh - 4rem);
}
```

### ¿Qué hace exactamente?

Calcula un valor final a partir de varios números y unidades compatibles.

Por ejemplo:

```css
.card {
  width: calc(50% - 1rem);
}
```

Esto significa: “toma la mitad del ancho del contenedor y resta 1rem”.

### Regla importante: deja espacios

Cuando usas `+` o `-`, debes dejar espacios alrededor:

```css
calc(100% - 2rem)
```

Esto es correcto.

Pero esto no lo es:

```css
calc(100%-2rem)
```

CSS lo interpreta mal o lo invalida. Los espacios importan.

### Operaciones soportadas

`calc()` puede hacer operaciones como:

- suma;
- resta;
- multiplicación con números;
- división con números;

Ejemplo:

```css
.box {
  width: calc(10px + 5%);
  margin: calc(1rem * 2);
}
```

Aunque la mayoría de las veces usarás suma y resta.

### Cuándo usar `calc()`

- cuando quieres restar un margen o padding a un ancho completo;
- cuando necesitas combinar porcentajes con unidades fijas;
- cuando quieres adaptar una caja a la pantalla sin media queries excesivas;
- cuando se mezclan unidades compatibles, como `%` + `rem`, `vw` + `px`, etc.

### Ejemplo real

```css
.layout {
  width: min(100%, 72rem);
  padding-inline: 1rem;
}

.card {
  width: calc(100% - 2rem);
}
```

Si el contenedor mide 1000px, la tarjeta con `calc(100% - 2rem)` quedará 32px menos ancha que el contenedor, dejando espacio a los lados.

### Cuándo no usarlo

Si la intención es tan simple como:

```css
width: 100%;
```

No necesitas `calc()`. No conviertas cada línea en una operación matemática por capricho. `calc()` debe resolver una relación real, no complicar la lectura.

## 3. `min()`, `max()` y `clamp()`: límites inteligentes

Estas funciones son muy útiles para layouts responsivos y textos adaptativos.

### `min()`: toma el valor más pequeño

```css
.container {
  width: min(75rem, 100%);
}
```

Esto significa: “usa el menor entre 75rem y 100%”.

Es como decir: “no me excedas de este ancho máximo, pero tampoco sobrepases el contenedor”.

### `max()`: toma el valor más grande

```css
.notice {
  padding-inline: max(1rem, 3vw);
}
```

Esto significa: “usa al menos 1rem, pero si `3vw` es más grande, usa ese valor”.

Es muy útil para asegurar que el padding no quede demasiado pequeño en pantallas estrechas.

### `clamp()`: el más útil para diseño fluido

```css
h1 {
  font-size: clamp(2rem, 1.2rem + 3vw, 4rem);
}
```

`clamp()` tiene esta forma:

```css
clamp(mínimo, preferido, máximo)
```

Significa:

- si el valor preferido es menor que el mínimo, usa el mínimo;
- si el valor preferido es mayor que el máximo, usa el máximo;
- en caso contrario, usa el valor preferido.

### Analogía

Es como un termostato: no puede ir más frío que el mínimo ni más caliente que el máximo. En diseño, hace que el texto o un bloque crezca de forma “controlada” según la pantalla.

### Ejemplo de texto responsivo

```css
.hero-title {
  font-size: clamp(2rem, 4vw, 4rem);
}
```

Esto hace que el título:

- no sea menor que `2rem`;
- crezca con el ancho de la pantalla;
- nunca exceda `4rem`.

### Ejemplo de ancho máximo adaptable

```css
.wrapper {
  width: min(100% - 2rem, 72rem);
  margin-inline: auto;
}
```

Esto hace que el contenedor:

- ocupe todo el ancho disponible, pero con un margen mínimo de `2rem`;
- no supere `72rem`;
- se centre automáticamente.

### ¿Por qué son tan importantes?

Porque permiten diseñar layouts fluidos sin necesitar docenas de media queries para cada pantalla.

## 4. Variables personalizadas y `var()`: el sistema de tokens de CSS

Las variables CSS, también llamadas custom properties, te permiten guardar valores reutilizables y hacer que el diseño sea más consistente y mantenible.

```css
:root {
  --space: 1rem;
  --surface: #ffffff;
  --text: #0f172a;
  --brand: #2563eb;
}

.card {
  color: var(--text);
  background: var(--surface);
  padding: var(--space);
}

.button-primary {
  background: var(--brand);
  color: white;
}
```

### ¿Qué hace `var()`?

`var(--nombre)` obtiene el valor de una variable CSS.

Si la variable existe, se usa. Si no existe, puedes aportar un valor por defecto:

```css
.card {
  padding: var(--space, 1rem);
}
```

Aquí, si `--space` no existe, el navegador usa `1rem`.

### ¿Qué hace que las variables sean tan útiles?

Porque respetan la cascada y la herencia.

Por ejemplo:

```css
:root {
  --surface: #ffffff;
  --text: #111827;
}

.card--dark {
  --surface: #111827;
  --text: #f8fafc;
}
```

Ahora los componentes hijos heredan esos valores desde la clase `.card--dark` sin repetir código.

### Analogía

Las variables son como poner nombres a los colores, espacios y valores base de tu sistema: en vez de escribir `#2563eb` 20 veces, defines `--brand` y reutilizas el nombre.

Eso da dos grandes ventajas:

- mantenimiento más fácil;
- cambios masivos con menos riesgo.

### Importante: las variables se heredan

Esto es clave. Si defines una variable en un elemento padre, sus hijos la pueden heredar a menos que la sobrescriban.

```css
.panel {
  --accent: #7c3aed;
}

.panel .button {
  background: var(--accent);
}
```

Esto permite crear temas y variantes con mucha claridad.

### Cuándo usar variables

Usa variables para:

- colores;
- espaciado (`--space-1`, `--space-2`, etc.);
- tamaños de fuente base;
- radii, sombras, z-index;
- temas y modos claro/oscuro.

### Qué no debes hacer

No conviertas todas las propiedades en variables por costumbre. Deben representar un valor significativo y reutilizable. Si cada valor es único y nunca se repite, probablemente no hace falta variable.

## 5. `env()`: valores del entorno del navegador

`env()` lee variables del entorno del navegador o del sistema operativo.

```css
header {
  padding-top: max(1rem, env(safe-area-inset-top));
}
```

### ¿Qué significa esto?

En dispositivos móviles con notch o barras de interfaz, el navegador puede exponer valores como:

- `safe-area-inset-top`
- `safe-area-inset-right`
- `safe-area-inset-bottom`
- `safe-area-inset-left`

Esto ayuda a evitar que el contenido quede detrás de una zona segura del dispositivo.

### Ejemplo práctico

```css
.card {
  padding: env(safe-area-inset-top) env(safe-area-inset-right)
    env(safe-area-inset-bottom) env(safe-area-inset-left);
}
```

Esto evita que los elementos se coloquen encima de áreas reservadas por el sistema.

### Analogía

`env()` es como preguntarle al navegador: “¿qué espacio me está dejando el sistema para que mi contenido no quede tapado?”

Es una función muy útil para interfaces móviles modernas, pero no la usarás tanto en layouts básicos.

## 6. `color-mix()`: mezclar colores de forma dinámica

`color-mix()` te permite combinar dos colores según proporciones.

```css
.button {
  background: color-mix(in srgb, var(--brand) 80%, white 20%);
}
```

Esto significa: “mezcla el color base con blanco en un 20%”.

### Casos habituales

- crear versiones más claras o más oscuras;
- generar fondos de hover;
- construir palettes automáticamente;
- evitar tener una variable para cada tono.

### Ejemplo con hover

```css
.button {
  background: var(--brand);
}

.button:hover {
  background: color-mix(in srgb, var(--brand) 80%, black 20%);
}
```

### Cuándo usarlo

Cuando quieres variar un color sin definir 10 variables manuales. Es especialmente útil en sistemas de diseño y temas.

### Cuidado

No es la función más simple para principiantes, y a veces la mezcla no es exactamente lo que esperas si no controlas el espacio de color. Es muy útil, pero debe usarse con intención.

## 7. `url()`: función para recursos

`url()` se usa para hacer referencia a recursos externos, como fuentes, imágenes o archivos de CSS.

```css
@font-face {
  src: url("/fonts/inter.woff2") format("woff2");
}
```

También se usa en `background-image`, aunque esta sección está enfocada más en funciones de cálculo y valor, no en imágenes de fondo.

### Importancia

Es la forma de decir: “usa este recurso”.

## 8. `attr()`: leer atributos HTML desde CSS

`attr()` permite leer un valor de un atributo HTML y usarlo en CSS.

```html
<button data-label="Guardar">OK</button>
```

```css
button::before {
  content: attr(data-label);
}
```

Esto puede ser útil en ciertos casos, aunque tiene limitaciones de compatibilidad y no es la más común en proyectos diarios.

Es una función interesante, pero no una base de todos los layouts. Se usa más en casos específicos o cuando necesitas crear contenido dinámico muy ligado al HTML.

## 9. Orden de evaluación: la parte mental más importante

Cuando el navegador resuelve CSS, no solo mira propiedades sueltas. Primero calcula los valores. Eso significa que funciones como `calc()`, `min()` o `clamp()` se evalúan antes de que la caja final se represente en pantalla.

Por eso es tan importante entender que:

- CSS calcula valores antes de dibujar;
- las funciones se integran en esa etapa;
- no se “muestran” como texto, sino como resultados numéricos o cadenas útiles para la propiedad.

## 10. ¿Qué función usar?

### Usa `calc()` cuando:

- necesitas combinar medidas;
- quieres restar padding, margin o ancho a un contenedor;
- una fórmula literal expresa la relación real.

### Usa `min()` cuando:

- quieres asegurarte de no exceder un máximo;
- necesitas elegir el valor menor entre dos opciones.

### Usa `max()` cuando:

- quieres un mínimo garantizado;
- necesitas que un valor no baja de cierta cifra.

### Usa `clamp()` cuando:

- tienes un tamaño que debe escalar con la pantalla;
- quieres un texto o bloque responsivo sin muchos breakpoints.

### Usa `var()` cuando:

- reutilizas tokens repetidos;
- construyes sistemas de diseño o temas;
- quieres cambiar valores globales sin tocar cada selector.

### Usa `env()` cuando:

- trabajas con dispositivos móviles y zonas seguras.

### Usa `color-mix()` cuando:

- quieres variantes de color dinámicas and no quieres 20 variables.

## 11. Regla de oro para funciones CSS

No uses una función solo porque existe. Úsala cuando exprese claramente una relación real.

Un buen CSS suele seguir esta lógica:

- si puedes expresar la idea con un valor literal, probablemente sea más simple;
- si la relación depende del contenedor, del viewport o de variables del sistema, una función tiene sentido;
- si una fórmula se vuelve ilegible, divide el problema en variables y te ahorra frustración.

## 12. Resumen mental

Las funciones CSS son la forma que tiene el lenguaje de hacer “cálculos y adaptaciones” para no quedar encasillado en valores fijos.

Las más importantes para empezar son:

- `calc()` para operaciones con medidas;
- `min()`, `max()`, `clamp()` para responsive y límites;
- `var()` para reutilizar valores y temas;
- `env()` para dispositivos y navegador;
- `color-mix()` para mezclar colores;
- `url()` para recursos y `attr()` para leer atributos cuando el contexto lo requiere.

Estas funciones son parte de la razón por la que CSS se siente tan poderoso: no solo define estilos, también define relaciones entre tamaños, contextos y entornos.

En otras palabras:

> CSS no es solo “poner colores y dimensiones”; es crear sistemas que respondan al entorno y a la intención del diseño.
