# 1.7. Ejercicio integrador: tarjeta de producto en oferta

## Contexto

TechStore lanzará una campaña de ofertas relámpago para su tienda en línea. El objetivo es crear una sección del catálogo con tarjetas de productos en descuento utilizando HTML semántico y accesible.

Este ejercicio reúne los temas estudiados en los fundamentos de HTML:

- estructura de documentos;
- HTML semántico;
- textos, imágenes y enlaces;
- atributos;
- clases e identificadores;
- accesibilidad;
- formularios y botones.

## Importante: ejercicio autónomo

Este ejercicio se resuelve de forma independiente.

**No debes subir la solución a la carpeta `exercises` ni modificar esa carpeta.**

Guarda tu trabajo en una ubicación personal de práctica. La documentación del reto permanece en la carpeta de fundamentos, pero la solución debe estar separada.

## Objetivo

Crear una sección de catálogo que muestre **exactamente tres productos en oferta**.

Cada producto debe presentarse como una tarjeta independiente y debe tener información propia. No repitas la misma tarjeta cambiando únicamente el nombre.

## Requisitos generales

La página debe:

- ser un documento HTML completo;
- utilizar HTML semántico;
- incluir una sección claramente identificable para las ofertas;
- contener exactamente tres productos;
- poder entenderse aunque no tenga estilos CSS;
- utilizar nombres descriptivos para clases e identificadores;
- respetar una estructura clara y ordenada;
- cumplir buenas prácticas de accesibilidad;
- evitar utilizar elementos genéricos cuando exista un elemento HTML con significado apropiado;
- no utilizar elementos genéricos como botones, títulos o imágenes.

## Requisitos de cada producto

Cada una de las tres tarjetas debe incluir los siguientes elementos:

### Insignia promocional

Debe mostrar un distintivo visible que indique que el producto está en promoción.

El texto puede ser:

- “Oferta”.
- “Oferta limitada”.
- “Descuento especial”.

### Imagen del producto

Debe incluir una fotografía o ilustración del producto.

La imagen debe:

- utilizar una ruta válida;
- tener un texto alternativo descriptivo;
- identificar claramente el producto representado;
- contar con dimensiones apropiadas;
- conservar su proporción.

### Nombre del producto

Debe mostrar el nombre completo y específico del producto como título de la tarjeta.

No utilices nombres genéricos como “Producto 1”, “Artículo” o “Elemento”.

### Compatibilidad o especificación

Debe incluir una línea breve con una característica útil del producto, como:

- compatibilidad;
- tipo de conexión;
- tamaño;
- resolución;
- capacidad;
- sistema compatible;
- otra especificación relevante.

### Valoración

Debe mostrar la valoración promedio del producto.

La valoración debe incluir:

- una representación visual de las estrellas o calificación;
- el valor numérico;
- una forma de entender la valoración sin depender solamente del color o de los símbolos.

Puedes elegir la cantidad de estrellas que corresponda a la valoración de cada producto. Estas son las opciones disponibles:

- **1 estrella:** `★☆☆☆☆`
- **2 estrellas:** `★★☆☆☆`
- **3 estrellas:** `★★★☆☆`
- **4 estrellas:** `★★★★☆`
- **5 estrellas:** `★★★★★`

El valor numérico debe coincidir con la cantidad de estrellas elegida. Por ejemplo, una valoración de 3 estrellas debe indicar también `3 de 5`.

### Precios

Debe mostrar claramente:

- el precio anterior tachado(Esta etiqueta no fue enseñada debes consultar por tus propios medios cómo se hace);
- el precio actual de oferta.

El precio anterior debe diferenciarse visualmente del precio vigente y el precio de oferta debe destacarse como el valor actual.

### Descripción

Debe incluir un párrafo corto con las características principales del producto.

La descripción debe:

- ser clara;
- ser breve;
- corresponder al producto;
- no repetir únicamente el nombre o la especificación;
- explicar por qué puede ser útil para el comprador.

### Llamado a la acción

Debe incluir un boton:

**“Añadir al carrito”**

## Accesibilidad

La solución debe:

- incluir el idioma principal del documento;
- mantener una jerarquía correcta de títulos;
- proporcionar textos alternativos para las imágenes;
- mostrar la valoración también como texto;
- diferenciar el precio anterior del precio actual mediante significado HTML;
- utilizar un control apropiado para la acción de compra;
- permitir comprender el contenido sin depender del color;
- mantener identificadores únicos;
- conservar un orden lógico para la navegación con teclado;
- utilizar atributos ARIA únicamente cuando aporten información necesaria.

## Clases e identificadores

Utiliza clases para identificar grupos de elementos que comparten una función o presentación.

Los nombres de las clases deben:

- ser descriptivos;
- relacionarse con el contenido o la función;
- mantenerse coherentes en las tres tarjetas;
- estar escritos en minúsculas;
- separar palabras de forma consistente;
- evitar nombres basados únicamente en colores, tamaños o posiciones;
- evitar nombres genéricos como `caja`, `cosa` o `elemento`.

Utiliza identificadores(id) únicamente cuando necesites identificar un elemento concreto dentro de la página. Cada identificador debe ser único.

## Productos

Los tres productos deben ser diferentes entre sí. Puedes elegir libremente los artículos tecnológicos, siempre que cada uno tenga:

- una imagen propia;
- un nombre propio;
- una especificación o compatibilidad diferente;
- una valoración;
- un precio anterior;
- un precio de oferta;
- una descripción propia;
- su propio llamado a la acción.
