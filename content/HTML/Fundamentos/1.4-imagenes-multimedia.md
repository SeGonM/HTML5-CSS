# 1.4. Imágenes y multimedia

Las imágenes ayudan a explicar, identificar o complementar el contenido de una página. En esta sesión aprenderás a organizarlas, enlazarlas correctamente y describirlas para que la experiencia no dependa únicamente de la vista.

> En la documentación nos enfocaremos principalmente en imágenes. Audio y video se estudiarán más adelante y no forman parte de las prácticas de esta sesión.

## 1. Organiza tus archivos

Antes de escribir el atributo `src`, decide dónde guardarás las imágenes. Una estructura sencilla puede ser:

```text
mi-proyecto/
├── index.html
├── paginas/
│   └── galeria.html
└── imagenes/
    ├── logo.webp
    ├── montanas.jpg
    └── iconos/
        └── mapa.svg
```

La ruta de una imagen se escribe desde el archivo HTML que la está utilizando, no desde la raíz del proyecto que ves en tu editor.

## 2. Rutas relativas

Una **ruta relativa** describe la ubicación de un recurso tomando como punto de partida la carpeta del archivo HTML actual. Es la opción habitual para imágenes que pertenecen al proyecto, porque sigue funcionando cuando el proyecto cambia de ordenador o de dominio.

Si `index.html` está en `mi-proyecto/` y la imagen está en `mi-proyecto/imagenes/montanas.jpg`, la ruta es:

```html
<img src="imagenes/montanas.jpg"
     alt="Montañas cubiertas de nieve">
```

### Moverse entre carpetas con `../`

`..` significa “subir una carpeta”. Si `galeria.html` está dentro de `paginas/`, para llegar a `imagenes/` primero debes subir a `mi-proyecto/`:

```html
<!-- paginas/galeria.html -->
<img src="../imagenes/montanas.jpg"
     alt="Montañas cubiertas de nieve">
```

Para subir dos niveles se repite el segmento:

```html
<!-- cursos/html/paginas/leccion.html -->
<img src="../../imagenes/logo.webp" alt="Logo del curso">
```

Cada `../` sube exactamente un nivel. No agregues `../` “por probar”: cuenta las carpetas desde el archivo HTML.

### Entrar en una subcarpeta con `/`

La barra `/` separa carpetas. Para entrar en `imagenes/iconos/`:

```html
<img src="imagenes/iconos/mapa.svg" alt="Mapa de ubicación">
```

Una ruta que comienza con `/`, como `/imagenes/logo.webp`, normalmente se interpreta como una ruta desde la raíz del sitio web. No es lo mismo que escribir la ruta de una carpeta de Windows:

```html
<!-- Ruta relativa dentro del proyecto -->
<img src="imagenes/logo.webp" alt="Logo">

<!-- Ruta absoluta de Internet -->
<img src="https://ejemplo.com/imagenes/logo.webp" alt="Logo">
```

No uses rutas del sistema como `C:\Users\...` en una página publicada. El navegador de otra persona no tiene acceso a tu ordenador y esa ruta dejará de funcionar fuera de él.

## 3. Rutas absolutas

Una **ruta absoluta** identifica el recurso completo sin depender de la carpeta del documento. En HTML suele ser una URL con protocolo:

```html
<img src="https://cdn.ejemplo.com/fotos/equipo.webp"
     alt="Equipo de trabajo reunido">
```

También puede usarse una ruta absoluta desde la raíz del sitio:

```html
<img src="/imagenes/logo.webp" alt="Logo del sitio">
```

La ruta desde la raíz depende de cómo esté publicado el sitio. Si el proyecto se publica dentro de `https://ejemplo.com/curso/`, `/imagenes/logo.webp` buscará `https://ejemplo.com/imagenes/logo.webp`, no necesariamente `https://ejemplo.com/curso/imagenes/logo.webp`. Para un proyecto de aprendizaje, las rutas relativas suelen ser más portables.

## 4. El elemento `<img>` y sus atributos

```html
<img
  src="imagenes/montanas.webp"
  alt="Lago rodeado de montañas al amanecer"
  width="1200"
  height="800"
  loading="lazy"
  decoding="async">
```

- `src` indica la ruta del archivo.
- `alt` comunica el propósito o la información importante de la imagen.
- `width` y `height` indican sus dimensiones esperadas y ayudan a evitar saltos de diseño mientras carga.
- `loading="lazy"` permite retrasar imágenes que están fuera de la vista inicial. No lo uses automáticamente en la imagen principal que aparece al abrir la página.
- `decoding="async"` permite que el navegador decida cómo decodificar la imagen sin bloquear otras tareas.

`width` y `height` no sustituyen la adaptación visual con CSS. Una imagen puede conservar sus proporciones con una regla como esta:

```css
img {
  max-width: 100%;
  height: auto;
}
```
(Aun no lo veremos en la documentación, pero es una práctica habitual para que las imágenes se adapten a distintos tamaños de pantalla.)

## 5. Escribe buenos textos alternativos

`alt` no es un pie de foto ni una lista de detalles visuales. Su objetivo es transmitir la misma información que la imagen aporta en ese contexto.

```html
<!-- La imagen comunica una acción -->
<img src="iconos/descargar.svg" alt="Descargar guía">

<!-- El texto cercano ya explica la imagen -->
<p>El proyecto tiene tres etapas.</p>
<img src="grafico-etapas.svg" alt="">

<!-- La imagen contiene información que debe poder leerse -->
<img src="horario.png"
     alt="Horario: HTML lunes, CSS miércoles y proyecto viernes">
```

Reglas prácticas:

- Incluye siempre `alt`, aunque su valor sea vacío (`alt=""`) para una imagen decorativa.
- No escribas “imagen de” o “foto de” salvo que ese dato sea relevante.
- No repitas en `alt` un texto que ya está inmediatamente junto a la imagen.
- Si una imagen contiene texto importante, incluye ese texto en la alternativa o acompáñala con una transcripción.
- Si la imagen es un enlace, describe el destino o la acción, no solo el aspecto de la imagen.

## 6. Formatos y peso de las imágenes

El formato debe corresponder al contenido:

- **AVIF:** buena compresión para fotografías y gráficos complejos; puede ser una opción muy ligera.
- **WebP:** formato moderno versátil para fotografías, ilustraciones y transparencias.
- **JPEG:** útil para fotografías cuando no se necesita transparencia.
- **PNG:** útil para transparencias y gráficos que necesitan bordes nítidos, aunque puede pesar más.
- **SVG:** adecuado para iconos y gráficos vectoriales simples; conserva su nitidez al escalar.

No conviertas todas las imágenes al mismo formato sin comprobar el resultado. Exporta cada archivo con dimensiones razonables para el tamaño al que se mostrará y comprueba que el texto, los bordes y los detalles sigan siendo legibles.

Cuando quieras ofrecer varios formatos de una misma imagen, puedes usar `<picture>`. Este elemento actúa como un contenedor para distintas fuentes y conserva un `<img>` como alternativa final:

```html
<picture>
  <source srcset="imagenes/montanas.avif" type="image/avif">
  <source srcset="imagenes/montanas.webp" type="image/webp">
  <img src="imagenes/montanas.jpg"
       alt="Montañas reflejadas en un lago"
       width="1200"
       height="800">
</picture>
```

`<picture>` no muestra una imagen por sí mismo: organiza las opciones. Cada `<source>` ofrece un archivo alternativo. `srcset` contiene la ruta del recurso y `type` informa su formato. El navegador elige la primera opción compatible y utiliza el `<img>` si ninguna fuente está disponible.

El `alt` debe escribirse en el `<img>`, no en `<source>`. Si solo tienes una imagen y no necesitas alternativas, basta con usar `<img>`.

## 7. Imágenes responsive con `srcset`

No todas las pantallas necesitan descargar la misma resolución. `srcset` permite ofrecer varias versiones:

```html
<img
  src="imagenes/galeria-800.webp"
  srcset="imagenes/galeria-400.webp 400w,
          imagenes/galeria-800.webp 800w,
          imagenes/galeria-1200.webp 1200w"
  sizes="(max-width: 600px) 100vw, 800px"
  alt="Personas observando una exposición"
  width="1200"
  height="800">
```

Los valores `400w`, `800w` y `1200w` informan del ancho de cada archivo. `sizes` indica cuánto espacio ocupará la imagen aproximadamente. El navegador elige una versión adecuada para la pantalla y la densidad del dispositivo.

Cuando ofreces diferentes tamaños de la misma imagen, usa `srcset` y `sizes`. `<picture>` es más apropiado cuando la decisión depende del formato o de una condición visual diferente.

## 8. Agrupar una imagen con su descripción

`<figure>` representa una unidad de contenido independiente, como una imagen, un diagrama o una ilustración. `<figcaption>` agrega un texto descriptivo visible para esa unidad:

```html
<figure>
  <img src="imagenes/diagrama-html.webp"
       alt="Documento HTML dividido en head y body"
       width="900"
       height="500">
  <figcaption>
    El documento separa los metadatos del contenido visible.
  </figcaption>
</figure>
```

- `<figure>` agrupa el recurso y su descripción.
- `<figcaption>` funciona como el pie o explicación de esa figura.

El texto del pie debe aportar contexto y no repetir exactamente el `alt`. Si el pie ya explica toda la información, el `alt` puede ser vacío:

```html
<figure>
  <img src="imagenes/flujo.svg" alt="">
  <figcaption>El navegador interpreta HTML, CSS y recursos multimedia.</figcaption>
</figure>
```

## 9. Audio y video

Aunque el curso se enfocará en imágenes, HTML también tiene elementos nativos para multimedia. `<audio>` reproduce sonido y `<video>` reproduce video. El atributo `controls` muestra los controles del navegador:

```html
<audio controls src="audio/introduccion.mp3"></audio>

<video controls width="640" height="360"
       poster="imagenes/miniatura.webp">
  <source src="video/clase.mp4" type="video/mp4">
  <track src="video/subtitulos-es.vtt"
         kind="subtitles"
         srclang="es"
         label="Español"
         default>
</video>
```

`<source>` también puede ofrecer diferentes archivos multimedia. En `<video>`, `<track>` permite añadir subtítulos mediante un archivo `.vtt`; `poster` define la imagen que se muestra antes de reproducir. En proyectos reales, evita la reproducción automática con sonido y ofrece alternativas accesibles.

## 10. Errores frecuentes

```html
<!-- La ruta no coincide con la ubicación real -->
<img src="imagen/montana.jpg" alt="Montaña">

<!-- El nombre real de la carpeta es imagenes -->
<img src="imagenes/montana.jpg" alt="Montaña">
```

En algunos servidores `Imagenes`, `imagenes` e `IMAGENES` son nombres distintos. Revisa también:

- la extensión real (`.jpg`, `.jpeg`, `.webp` o `.avif`);
- mayúsculas y minúsculas;
- cantidad de `../`;
- espacios y caracteres especiales en nombres;
- que el archivo esté dentro de la carpeta publicada.
