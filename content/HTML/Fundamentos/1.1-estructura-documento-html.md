# 1.1. Estructura de un documento HTML

Un documento HTML tiene un orden reconocible. No se trata de una plantilla que se copia sin pensar: cada parte cumple una función y ayuda al navegador a interpretar la página correctamente.

Cuando la estructura está clara, es más fácil:

- localizar y modificar el contenido;
- evitar errores de interpretación del navegador;
- trabajar después con CSS;
- ofrecer información útil a buscadores y tecnologías de asistencia.

## La estructura mínima

Este es un punto de partida completo para una página en español:

```html
<!doctype html>
<html lang="es">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <meta name="description" content="Introducción a la estructura de un documento HTML">
    <title>Introducción a HTML</title>
  </head>
  <body>
    <h1>Aprendiendo HTML</h1>
    <p>HTML organiza el contenido de una página web.</p>
  </body>
</html>
```

El navegador lee el documento desde arriba hacia abajo. Los elementos se relacionan entre sí como un árbol: `<html>` contiene a `<head>` y `<body>`, y estos contienen otros elementos. Por eso el orden y el anidamiento importan.

## El documento paso a paso

### `<!doctype html>`

Es la declaración del tipo de documento. Le indica al navegador que debe interpretar la página usando el modo estándar de HTML5.

No es una etiqueta y no necesita una etiqueta de cierre. Debe aparecer en la primera línea del archivo, antes de cualquier elemento HTML.

### `<html>`

Es el elemento raíz: todo el documento está dentro de él.

El atributo `lang` indica el idioma principal del contenido:

```html
<html lang="es">
```

Usar el idioma correcto ayuda a los lectores de pantalla a pronunciar el texto y permite que otras herramientas procesen mejor la página. Si el contenido principal estuviera en inglés, usaríamos `lang="en"`.

### `<head>`

El `<head>` contiene información sobre el documento. Normalmente no se muestra como contenido de la página, aunque influye en cómo se presenta y se identifica.

En esta zona suelen aparecer:

- la codificación de caracteres;
- la configuración para diferentes tamaños de pantalla;
- el título de la página;
- una descripción breve;
- referencias a hojas de estilos y otros recursos.

El `<head>` no es el lugar para escribir el texto que queremos que la persona lea en la página. Ese contenido pertenece al `<body>`.

### La codificación de caracteres

```html
<meta charset="utf-8">
```

`UTF-8` permite representar letras con tildes, eñes, símbolos y muchos otros caracteres. Colocar esta declaración al principio del `<head>` evita que el navegador muestre caracteres extraños cuando el archivo contiene texto en español.

### La configuración de pantalla

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Esta configuración indica que el ancho de la página debe adaptarse al ancho del dispositivo y que la escala inicial debe ser normal. Es especialmente importante en teléfonos y tabletas. Por sí sola no hace que una página sea responsive, pero permite que el navegador la mida correctamente.

### `<title>`

```html
<title>Introducción a HTML</title>
```

Define el título del documento. Puede verse en la pestaña del navegador, en los marcadores y en otros lugares donde se identifica la página.

Cada página debe tener un título breve y descriptivo. `Página 1` aporta poca información; `Estructura de un documento HTML` permite reconocer mejor el contenido.

### La descripción

```html
<meta
  name="description"
  content="Introducción a la estructura de un documento HTML"
>
```

La descripción resume el propósito de la página. Puede ser utilizada por buscadores y vistas previas, aunque no sustituye un título claro ni un contenido bien escrito.

### `<body>`

El `<body>` contiene el contenido que forma parte de la página: títulos, párrafos, enlaces, imágenes, formularios y demás elementos que veremos en las siguientes sesiones.

En este nivel basta con recordar la separación principal:

```html
<head>
  <!-- Información sobre el documento -->
</head>
<body>
  <!-- Contenido de la página -->
</body>
```

## Etiquetas, elementos y contenido

Una etiqueta es una instrucción escrita entre signos menor y mayor. Un elemento normalmente está formado por una etiqueta de apertura, contenido y una etiqueta de cierre:

```html
<p>Este es el contenido del párrafo.</p>
```

En el ejemplo:

- `<p>` es la etiqueta de apertura;
- `Este es el contenido del párrafo.` es el contenido;
- `</p>` es la etiqueta de cierre;
- todo el conjunto es el elemento `p`.

La barra `/` indica que una etiqueta se está cerrando. El nombre debe coincidir con el de apertura.

## Anidamiento correcto

Los elementos pueden estar dentro de otros, pero deben cerrarse en el orden inverso al que se abrieron:

```html
<p>Texto <strong>importante</strong> dentro del párrafo.</p>
```

Primero se abre `<p>`, después `<strong>`, se cierra `<strong>` y finalmente `<p>`. Piensa en los elementos como cajas dentro de otras cajas: una caja interior debe terminar antes de cerrar la caja exterior.

Este ejemplo es incorrecto porque los elementos se cruzan:

```html
<!-- Incorrecto -->
<p><strong>Texto</p></strong>
```

Los navegadores suelen intentar corregir este tipo de errores, pero no debemos depender de esa corrección. Un HTML ordenado es más predecible y fácil de mantener.

## Elementos vacíos

Algunos elementos no contienen texto ni otros elementos, por lo que no tienen etiqueta de cierre. Se conocen como elementos vacíos:

```html
<meta charset="utf-8">
<img src="paisaje.webp" alt="Montañas al amanecer">
<br>
```

No escribas `</meta>` ni `</br>`. En HTML5 tampoco es necesario añadir una barra al final, como en `<br />`; la forma habitual es `<br>`.

## Atributos

Los atributos añaden información a un elemento o modifican su comportamiento. Se escriben en la etiqueta de apertura, después del nombre del elemento:

```html
<html lang="es">
<img src="paisaje.webp" alt="Montañas al amanecer">
```

En el segundo ejemplo:

- `src` indica la ubicación del archivo de imagen;
- `alt` describe la imagen cuando no puede verse o cuando se utiliza un lector de pantalla.

Los valores suelen escribirse entre comillas. No mezcles comillas de apertura y cierre ni pongas atributos fuera de la etiqueta:

```html
<!-- Correcto -->
<p class="intro">Texto introductorio.</p>
```

`id` identifica un elemento concreto dentro de la página, por lo que no debería repetirse. `class` permite agrupar varios elementos que comparten una característica. Por ejemplo, varios títulos de tarjetas podrían usar `class="card-title"`.

## Comentarios e indentación

Los comentarios sirven para dejar una nota en el código. El navegador no los muestra como contenido:

```html
<!-- Este comentario explica una decisión del documento -->
<h1>Aprendiendo HTML</h1>
```

Úsalos cuando aporten contexto, no para repetir lo que el código ya expresa. Una indentación consistente también ayuda a identificar qué elementos están dentro de otros:

```html
<body>
  <h1>Título de la página</h1>
  <p>Texto introductorio.</p>
</body>
```

Los espacios y saltos de línea hacen el código más legible. No cambies la indentación para simular espacios visuales; la presentación corresponde a CSS, que veremos más adelante.

## Errores frecuentes

- Omitir `<!doctype html>` o colocarlo después de otro contenido.
- Escribir el contenido visible dentro de `<head>`.
- Olvidar cerrar un elemento que necesita cierre.
- Cruzar etiquetas al anidar elementos.
- Repetir el mismo `id` en varios elementos.
- Escribir atributos sin comillas o fuera de la etiqueta de apertura.
- Olvidar `lang`, `charset` o un `<title>` descriptivo.
- Usar etiquetas HTML para conseguir un aspecto visual en lugar de describir el contenido.
