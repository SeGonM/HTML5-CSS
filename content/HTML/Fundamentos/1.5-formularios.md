# 1.5. Formularios

Los formularios permiten recibir información de las personas. Un formulario accesible explica qué dato solicita, ofrece controles adecuados y comunica los errores de forma clara.

## Estructura básica

```html
<form action="/registro" method="post">
  <div>
    <label for="nombre">Nombre completo</label>
    <input id="nombre" name="nombre" type="text" autocomplete="name"
           required>
  </div>

  <div>
    <label for="correo">Correo electrónico</label>
    <input id="correo" name="correo" type="email"
           autocomplete="email" required>
  </div>

  <button type="submit">Crear cuenta</button>
</form>
```

`action` indica dónde se envía la información y `method="post"` evita colocar los datos del formulario en la URL. Cada control que se envía debe tener un atributo `name`.

## Asociación de etiquetas

El valor de `for` debe coincidir con el `id` del control:

```html
<label for="mensaje">Mensaje</label>
<textarea id="mensaje" name="mensaje" rows="5" required></textarea>
```

También puedes agrupar opciones relacionadas:

```html
<fieldset>
  <legend>Preferencias de contacto</legend>
  <label><input type="checkbox" name="canales" value="email"> Correo</label>
  <label><input type="checkbox" name="canales" value="sms"> SMS</label>
</fieldset>
```

## Tipos de input modernos

```html
<input type="date" name="fecha">
<input type="number" name="cantidad" min="1" max="10">
<input type="url" name="sitio">
<input type="tel" name="telefono" autocomplete="tel">
<input type="search" name="consulta">
```

El tipo adecuado ofrece un teclado y validación más útiles según el dispositivo. Para opciones mutuamente excluyentes usa radios:

```html
<label><input type="radio" name="nivel" value="inicial" required> Inicial</label>
<label><input type="radio" name="nivel" value="intermedio"> Intermedio</label>
```

## Validación HTML5

Atributos como `required`, `min`, `max`, `minlength`, `maxlength`, `pattern` y los tipos `email` o `url` permiten una validación inicial en el navegador:

```html
<label for="usuario">Usuario</label>
<input id="usuario" name="usuario" type="text"
       minlength="3" maxlength="20"
       pattern="[A-Za-z0-9_]+"
       aria-describedby="ayuda-usuario" required>
<small id="ayuda-usuario">Usa entre 3 y 20 letras, números o guiones bajos.</small>
```

La validación del navegador mejora la experiencia, pero nunca sustituye la validación del servidor. No uses `placeholder` como reemplazo de un `<label>`.
