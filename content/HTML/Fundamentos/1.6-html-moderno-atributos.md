# 1.6. HTML moderno y atributos

Los atributos agregan información a las etiquetas HTML. Algunos ayudan a identificar elementos, otros indican su idioma, estado, relación o comportamiento.

En esta sesión aprenderás a usar atributos globales, a nombrar correctamente tus `class` e `id`, a guardar datos con `data-*` y a mejorar la accesibilidad con `aria-*`.

## 1. ¿Qué es un atributo?

Un atributo se escribe dentro de la etiqueta de apertura:

```html
<p class="introduccion" lang="es">Aprendemos HTML.</p>
```

En este ejemplo:

- `class` es el nombre del atributo.
- `"introduccion"` es su valor.
- `lang="es"` indica que el texto está en español.

Los atributos no deben escribirse al azar. Cada uno tiene un propósito y debe colocarse en el elemento adecuado.

## 2. `class`: agrupar elementos

`class` permite poner uno o varios nombres a un elemento. Su uso principal es aplicar los mismos estilos a varios elementos desde CSS.

```html
<article class="tarjeta">
  <h2 class="tarjeta__titulo">Aprende HTML</h2>
  <p class="tarjeta__texto">Una introducción práctica.</p>
</article>

<article class="tarjeta">
  <h2 class="tarjeta__titulo">Aprende CSS</h2>
  <p class="tarjeta__texto">Da estilo a tus páginas.</p>
</article>
```

Las dos tarjetas comparten `tarjeta`, por lo que CSS puede darles la misma apariencia. Los títulos comparten `tarjeta__titulo` y los párrafos comparten `tarjeta__texto`.

Un elemento puede tener varias clases separadas por espacios:

```html
<button class="boton boton--principal">Guardar cambios</button>
```

Aquí:

- `boton` representa el estilo general.
- `boton--principal` representa una variante de ese botón.

## 3. Cómo nombrar buenas clases

Una clase debe describir el papel o el significado del elemento, no su apariencia momentánea.

### Nombres recomendados

```html
<header class="encabezado">
  <nav class="navegacion-principal">
    <a class="enlace-navegacion" href="/cursos">Cursos</a>
  </nav>
</header>

<section class="lista-cursos">
  <article class="tarjeta-curso">...</article>
</section>
```

Estos nombres indican qué representa cada bloque. Si mañana cambias el color o la posición, los nombres seguirán teniendo sentido.

### Nombres que conviene evitar

```html
<!-- El nombre describe una apariencia y puede dejar de ser cierto -->
<p class="texto-rojo">Información importante.</p>

<!-- El nombre describe una posición demasiado concreta -->
<div class="caja-izquierda">...</div>

<!-- Es difícil saber qué representa -->
<div class="caja1">...</div>
```

Es mejor escribir `mensaje-error`, `panel-informacion` o `tarjeta-producto`. CSS se encargará de decidir si algo es rojo, grande, pequeño, horizontal o está a la izquierda.

### Reglas prácticas para nombres

1. Usa nombres descriptivos: `formulario-contacto` comunica más que `caja2`.
2. Escribe en minúsculas.
3. Separa palabras con guiones: `menu-principal`.
4. No uses espacios dentro de una palabra.
5. No empieces un nombre con un número.
6. Evita tildes, espacios y caracteres especiales.
7. Mantén un idioma y un estilo coherentes en todo el proyecto.
8. No cambies el nombre de una clase solo porque cambió su color o posición.

```html
<!-- Claro y consistente -->
<section class="perfil-usuario">
  <h2 class="perfil-usuario__nombre">Ana López</h2>
</section>
```

## 4. Una convención sencilla para CSS

Una convención es una forma acordada de escribir nombres. No es una etiqueta nueva ni una regla obligatoria, pero ayuda a que el proyecto sea fácil de mantener.

Una opción sencilla es usar:

- `bloque`: componente independiente.
- `bloque__parte`: elemento que pertenece al bloque.
- `bloque--variante`: versión diferente del bloque.

```html
<article class="producto producto--destacado">
  <img class="producto__imagen"
       src="imagenes/libro.webp"
       alt="Libro de HTML">
  <h2 class="producto__titulo">HTML desde cero</h2>
  <p class="producto__descripcion">Una guía para comenzar.</p>
  <a class="producto__enlace" href="/detalle">Ver detalle</a>
</article>
```

En este ejemplo, `producto` es el bloque, `producto__imagen` y `producto__titulo` son partes del bloque, y `producto--destacado` es una variante.

También puedes usar nombres simples como `tarjeta`, `titulo-seccion` y `menu-principal`. Lo importante es ser descriptivo y repetir la misma lógica.

## 5. `id`: identificar un único elemento

`id` identifica un elemento de forma única dentro de una página. Dos elementos no deben tener el mismo `id`.

```html
<h1 id="inicio">Ruta de aprendizaje HTML</h1>
```

Un `id` puede servir como destino de un enlace:

```html
<a href="#formularios">Ir a la sección de formularios</a>

<section id="formularios">
  <h2>Formularios</h2>
</section>
```

Al pulsar el enlace, el navegador se desplaza hasta el elemento cuyo `id` es `formularios`.

También usamos `id` para relacionar etiquetas:

```html
<label for="correo">Correo electrónico</label>
<input id="correo" name="correo" type="email">
```

El valor de `for` y el valor de `id` deben coincidir exactamente.

## 6. Diferencias entre `class` e `id`

| Característica | `class` | `id` |
|---|---|---|
| Cantidad | Puede repetirse | Debe ser único |
| Uso habitual | Agrupar y aplicar estilos | Identificar un elemento concreto |
| Ejemplo | `class="tarjeta"` | `id="contacto"` |
| Enlaces internos | No es su uso principal | Puede ser destino de `href="#..."` |
| Formularios | Puede decorar o agrupar | Relaciona `label` con `input` |

```html
<section id="recursos" class="seccion seccion--clara">
  <h2 class="seccion__titulo">Recursos</h2>
</section>
```

El `id` identifica esta sección concreta. Las clases indican que es una sección y que tiene una variante visual.

### ¿Debo usar `id` para todo?

No. Para estilos que se repiten, usa `class`. Reserva `id` para identificadores únicos, destinos de enlaces y relaciones entre elementos. Usar muchos `id` para estilos puede hacer que el CSS sea más difícil de modificar.

## 7. Atributos globales útiles

Los atributos globales pueden utilizarse en muchos elementos HTML:

```html
<article class="articulo" lang="es" title="Artículo destacado">
  <h2>HTML semántico</h2>
  <p>Una estructura clara ayuda a todas las personas.</p>
</article>
```

- `lang` indica el idioma del contenido.
- `title` ofrece información adicional cuando se pasa el cursor, pero no debe contener información esencial.
- `hidden` oculta un elemento hasta que sea necesario mostrarlo.
- `dir="rtl"` indica una escritura de derecha a izquierda.
- `spellcheck="false"` desactiva la revisión ortográfica en un campo concreto.

Usa cada atributo solo cuando tenga un motivo claro:

```html
<p lang="en">This short phrase is in English.</p>
<p hidden>Este aviso todavía no debe mostrarse.</p>
```

`tabindex` también puede cambiar el orden del teclado, pero no lo uses para convertir elementos normales en botones. Es mejor elegir el elemento HTML correcto, como `<button>` o `<a>`.

## 8. Atributos `data-*`

Los atributos `data-*` permiten guardar una pequeña información relacionada con un elemento. El nombre siempre comienza con `data-`:

```html
<article class="tarjeta-curso"
         data-tema="html"
         data-nivel="inicial">
  <h2>Fundamentos de HTML</h2>
</article>
```

Aquí `data-tema` y `data-nivel` describen datos propios de esa tarjeta. No inventes atributos como `tema="html"`: si necesitas guardar un dato personalizado, usa `data-*`.

No uses `data-*` para reemplazar atributos que HTML ya tiene:

```html
<!-- Incorrecto: HTML ya tiene el atributo alt -->
<img src="logo.webp" data-alt="Logo del curso">

<!-- Correcto -->
<img src="logo.webp" alt="Logo del curso">
```

Los datos de `data-*` se pueden utilizar más adelante para crear interacciones, pero por ahora basta con saber que son datos descriptivos personalizados.

## 9. Accesibilidad con `aria-*`

Los atributos `aria-*` aportan información adicional a las tecnologías de asistencia cuando el HTML nativo no es suficiente. Primero elige el elemento correcto:

```html
<!-- Mejor: el botón ya tiene significado y comportamiento -->
<button type="button">Mostrar menú</button>

<!-- Evita usar un div como si fuera un botón -->
<div class="boton-falso">Mostrar menú</div>
```

Algunos atributos ARIA frecuentes son:

- `aria-label`: proporciona un nombre cuando no existe un texto visible adecuado.
- `aria-labelledby`: toma el nombre desde otro elemento identificado por su `id`.
- `aria-describedby`: relaciona un control con una explicación.
- `aria-current="page"` indica el enlace de la página actual.
- `aria-expanded` indica si un panel está abierto o cerrado.
- `aria-controls` relaciona un control con el elemento que controla.

```html
<button type="button"
        aria-expanded="false"
        aria-controls="menu-cursos">
  Cursos
</button>

<ul id="menu-cursos" hidden>
  <li><a href="/html">HTML</a></li>
  <li><a href="/css">CSS</a></li>
</ul>
```

`aria-expanded="false"` indica que el menú está cerrado y `aria-controls="menu-cursos"` señala qué elemento está relacionado. `hidden` mantiene el menú oculto. Cuando se abra, esos estados deberán cambiar juntos.

## 10. Elementos modernos: `<details>` y `<summary>`

`<details>` crea una sección que se puede abrir y cerrar. `<summary>` es el texto que se pulsa para cambiar su estado:

```html
<details>
  <summary>¿Qué aprenderé en HTML?</summary>
  <p>Aprenderás a estructurar textos, imágenes, enlaces y formularios.</p>
</details>
```

Estos elementos ya incluyen un comportamiento útil sin tener que crear controles complicados. Si quieres que aparezca abierto al cargar la página, añade `open`:

```html
<details open>
  <summary>Consejo</summary>
  <p>Usa nombres descriptivos para tus clases.</p>
</details>
```

## 11. Ejemplo integrador

Este ejemplo combina etiquetas semánticas, nombres de clases descriptivos, un `id` único, datos personalizados y atributos de accesibilidad:

```html
<section id="curso-html"
         class="curso curso--destacado"
         data-nivel="inicial"
         aria-labelledby="curso-titulo">
  <h2 id="curso-titulo" class="curso__titulo">Fundamentos de HTML</h2>
  <p class="curso__descripcion">
    Aprende a crear documentos claros y accesibles.
  </p>

  <details class="curso__detalles">
    <summary class="curso__resumen">Ver temas del curso</summary>
    <ul class="curso__lista">
      <li>Estructura de documentos</li>
      <li>Imágenes y multimedia</li>
      <li>Formularios</li>
    </ul>
  </details>
</section>
```

Observa que:

1. `curso` identifica el componente general.
2. `curso--destacado` es una variante.
3. `curso__titulo`, `curso__descripcion` y `curso__lista` son partes del componente.
4. `id="curso-html"` identifica una sección única.
5. `data-nivel` guarda un dato descriptivo.
6. `aria-labelledby` relaciona la sección con su título.
7. `<details>` y `<summary>` crean una interacción nativa.

## 12. Lista de comprobación

Antes de terminar una página, revisa:

- ¿Las clases describen el papel del elemento y no solo su color o posición?
- ¿Las clases repetidas tienen exactamente el mismo nombre?
- ¿Cada `id` es único?
- ¿Los `for` de los labels coinciden con los `id` de sus controles?
- ¿Usaste HTML nativo antes de añadir `aria-*`?
- ¿Los datos personalizados empiezan por `data-`?
- ¿El idioma está indicado cuando el contenido cambia de idioma?
- ¿Los elementos ocultos con `hidden` volverán a mostrarse de forma clara?
