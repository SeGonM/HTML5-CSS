# 1.6. HTML moderno y atributos

Los atributos amplían la información y el comportamiento de los elementos. HTML moderno combina atributos globales, datos específicos de la aplicación y recursos de accesibilidad sin perder la semántica nativa.

## Atributos globales

```html
<article id="introduccion" class="card card--featured"
         lang="es" title="Artículo destacado">
  <h2>Introducción a HTML</h2>
  <p>Contenido para comenzar el curso.</p>
</article>
```

- `id` identifica un elemento de forma única y puede servir como destino de un enlace.
- `class` agrupa elementos para CSS y JavaScript.
- `lang` declara el idioma de un fragmento.
- `title` ofrece información adicional, pero no debe ser la única forma de comunicar algo importante.

Otros atributos globales frecuentes son `hidden`, `tabindex`, `contenteditable`, `dir` y `spellcheck`. Úsalos solo cuando su comportamiento sea realmente necesario.

## Atributos `data-*`

Los atributos personalizados `data-*` guardan datos pequeños relacionados con un elemento:

```html
<button type="button" class="js-filtro"
        data-category="html"
        data-count="6">
  Filtrar HTML
</button>
```

JavaScript puede leerlos mediante `element.dataset.category`. No uses `data-*` para reemplazar atributos HTML existentes, ni para almacenar secretos: cualquier persona puede verlos en el navegador.

## Accesibilidad con `aria-*`

Prefiere siempre HTML nativo antes de añadir ARIA:

```html
<button type="button" aria-expanded="false"
        aria-controls="menu-cursos">
  Cursos
</button>
<ul id="menu-cursos" hidden>
  <li><a href="/html">HTML</a></li>
</ul>
```

`aria-expanded` comunica el estado del control y `aria-controls` relaciona el botón con el contenido. El comportamiento que abre y cierra el menú debe actualizar ambos estados (`aria-expanded` y `hidden`).

Un enlace debe seguir siendo un `<a>` y un botón debe seguir siendo un `<button>`. No conviertas un `<div>` en un control interactivo solo con ARIA: perderías teclado, foco y comportamiento nativo.

## Atributos útiles de HTML moderno

```html
<details>
  <summary>¿Qué es HTML?</summary>
  <p>Es el lenguaje que estructura el contenido de la web.</p>
</details>

<label for="tema">Tema</label>
<select id="tema" name="tema">
  <option value="html">HTML</option>
  <option value="css">CSS</option>
</select>
```

`<details>` y `<summary>` ofrecen un panel desplegable nativo. Los elementos nativos suelen requerir menos código y funcionar mejor con teclado y tecnologías de asistencia.
