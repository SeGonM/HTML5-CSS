| Objetivo | Público | Enfoque |

## 🗂 Roadmap (resumen)

| # | Módulo | Temas clave | Mini reto |
|---:|---|---|---|
| 1 | Fundamentos absolutos | Estructura, etiquetas semánticas, texto, imágenes | CV estático |
| 2 | CSS básico & box model | Selectores, cascada, box model, display | Tarjeta de presentación |
| 3 | Posicionamiento clásico | position, floats, z-index | Cabecera fija + botón flotante |
| 4 | Tipografía & UI | Fuentes web, unidades relativas, ritmo vertical | Artículo con tipografía cuidada |
| 5 | Responsive esencial | Mobile‑first, media‑queries, imágenes responsivas | Landing responsiva |
| 6 | Flexbox | Ejes, alignment, patrones comunes | Grid de tarjetas (Flexbox) |
| 7 | CSS Grid | Template, gap, áreas, subgrid | Layout tipo magazine |
| 8 | Sistemas & metodología | BEM, variables CSS, componentización | Mini biblioteca de componentes |
| 9 | Patrones adaptativos | Breakpoints, container queries (cuando) | Layout adaptable |
|10 | Interactividad con CSS | Transitions, transforms, keyframes | Menú desplegable puro CSS |
|11 | Accesibilidad | ARIA básicos, focus, contraste | Audit y mejoras accesibles |
|12 | Técnicas avanzadas | clip-path, object-fit, aspect-ratio | Cabecera con máscara |
|13 | Layouts complejos | Masonry CSS, multi-column | Dashboard estático |
|14 | Rendimiento | Critical CSS, preload, fonts | Optimizar página (Lighthouse) |
|15 | Testing & compat | DevTools, fallbacks | Compatibilidad entre navegadores |
|16 | Preprocesadores | Sass, PostCSS, Autoprefixer | Migrar a Sass y compilar |
|17 | CSS moderno | Container Queries, Houdini (conceptos) | Prototipo con CSS moderno |
|18 | Design Systems | Tokens, theming con variables | Mini design system |
|19 | Casos especiales | Emails, @media print, SVG | Newsletter responsive |
|20 | Proyectos finales | Portfolio, dashboard, catálogo | Crear proyecto completo |

## 🛠 Cómo usar este repo (rápido)

| Paso | Qué hacer |
|---:|---|
| 1 | Fork del repo |
| 2 | Crear rama: `feature/<tu-nombre>` |
| 3 | Añadir tu solución en carpeta `/solutions/<tu-nombre>/` |
| 4 | Abrir Pull Request describiendo cambios y reto resuelto |

---

## 🤝 Contribuir

- Correcciones pequeñas: abre un PR con la edición puntual.
- Soluciones de retos: sube tu HTML/CSS en una carpeta con README corto.
- Revisión: comentarios respetuosos y enfocados en aprendizaje.
